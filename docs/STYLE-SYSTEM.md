# 风格系统

这份文档记录 2.10.0 外观、风格和微调三层的来源及后续变动。表格里的数量、默认值与分类描述对应当时版本。当前入口见 [应用层](parts/app.md) 和 [导演](parts/director.md)。4.0.0 的风格所有权、完整预设、可组合外观及布局要求见 [项目方向](DIRECTION.md)。

## 1. 2.10.0 的历史决定

| # | 问题 | 决定 |
|---|---|---|
| 1 | 主题拆成「外观」与「风格」两层 | 可以 |
| 2 | 六个风格的名称与适用歌曲 | 不改 |
| 3 | 旋钮合并为 5 个，细项移入「高级」 | 可以 |
| 4 | 新歌的默认 | 外观维持「封面」，风格用它原本的动态（＝叙事）；推荐的风格只标「推荐」，不自动套用 |
| 5 | 字体依歌词过滤 | 可以；**以歌词实际用到的每个字判断**，不以「繁中／简中／日文」标签判断。同时支持正体与简体的字体，两种歌词都要列在「可完整显示」里 |

## 2. 三层结构

| 层 | 管什么 | 包含的设置 | 专辑连播时 |
|---|---|---|---|
| 外观 | 看起来怎样 | 背景、配色、字体、氛围与画面质感特效、封面／视频的呈现方式 | 沿用第一首 |
| 风格 | 歌词怎么动 | 镜头、歌词类型、入场、退场、未唱的字、转场、闪光方式、动态基准值 | 每首各自 |
| 微调 | 在风格上加减 | 5 个旋钮＋字号；「高级」里保留全部细项 | 每首各自 |

## 3. 外观（原五个主题）

| 外观 | 背景 | 默认字体 | 默认特效 | 备注 |
|---|---|---|---|---|
| 封面（新歌默认） | 封面 | 思源黑体 | 光点、暗角、歌词框线 | 配色取自封面 |
| 液态 | 液态流动 | 圆体（Zen Maru） | 光点、暗角、星星 | |
| 哥特 | 哥特 | 书卷衬线 | 光点、暗角、颗粒、碎玻璃、字形纹样 | 碎玻璃为专属特效 |
| 视频 | 视频 | 思源黑体 | 光点、暗角、颗粒、歌词框线 | 仅工作坊与绑定 MV 时 |
| 唱片 | 唱片 | 思源黑体 | 门框、背景线条、立体线条、碎块 | 四个都是专属特效；纯音乐默认 |

## 4. 风格

| 风格 | 镜头 | 歌词类型 | 入场 | 退场 | 适合 | 推荐条件（初稿） |
|---|---|---|---|---|---|---|
| 叙事（新歌默认） | 滑行 | 流动 | 位移飘入 | 淡出 | 中速流行、抒情 | 80–120 BPM，能量中等 |
| 圆舞 | 圆舞 | 流动 | 逐字上浮 | 淡出并上飘 | 慢歌、3/4 拍、温柔 | 3 拍子，或 < 90 BPM 且能量低 |
| 律动 | 俐落 | 流动 | 冲击放大 | 淡出 | 快歌、电子、摇滚 | > 120 BPM 且能量高、有鼓 |
| 特写 | 特写 | 流动 | 字距收拢 | 淡出 | 说唱、念白、字密 | 歌词密度 > 每秒约 5 字 |
| 漂浮 | 悬停 | 圆心 | 模糊对焦 | 渐大字距后淡出 | 氛围、梦幻、后摇 | 没有鼓或鼓很少，且铺底音色多 |
| 舞台 | 置中 | 整句 | 逐字上浮 | 淡出 | 纯音乐、卡拉OK、MV 字幕感 | 纯音乐，或没有人声 |

- 推荐用到的数据：速度、拍号、整体能量、鼓声覆盖率、人声有无、歌词密度（音节／秒）、是否标为纯音乐。
- 推荐只在菜单上标示，不自动套用；也只推荐一个，同分时取表格中较前面的。
- 各风格的动态基准值（震动、摆动、转向、纵深……）先取自现在最接近的主题，实现时再逐一调。
- **我的风格**（`app/motions.ts`，存在这台电脑的设置里）：把目前的动态存成自己的风格——镜头、歌词类型、入场、退场、转场、未唱字的显示、动态基准值（`m0`）与字号以外的所有旋钮（`motionPart`）。在任何一首歌的「风格」菜单里跟内置风格并列，套用时（`withSavedMotion`）外观与字号不变；样式记下来源（`motionId`、`motionName`），所以再按保存会覆写同一个，也能另存或删除。改选内置风格就离开自订风格。

## 5. 旋钮：13 → 5（＋字号）

| 新旋钮 | 合并自 | 范围 |
|---|---|---|
| 速度 | 运镜速度 | 0.4–1.6 |
| 力度 | 重音力道、重拍触发灵敏度 | 0–2 |
| 律动 | 律动、文字节奏颤动 | 0–4 |
| 空间 | 空间纵深、漂浮感、转向幅度 | 0–2 |
| 字感 | 进场时长、光晕与投影 | 0.15–1.6（进场）／0–2（光晕） |
| 字号 | 歌词字号（跟着项目，不跟着风格） | 0.6–2 |

| 移走的旋钮 | 去处 |
|---|---|
| 字形纹样频率 | 「字形纹样」特效自己的参数 |
| 残影色散 | 特效清单，改名「文字残影」（和画面的「色散」分开） |
| 全部 13 个细旋钮 | 「高级」里原样保留 |

## 6. 特效分组

| 组 | 特效 | 显示条件 |
|---|---|---|
| 氛围 | 光点、羽毛、星星、节拍光环、频谱、网格地面 | 一律 |
| 画面质感 | 颗粒质感、暗角、扫描线、色散、故障、反色几何 | 一律 |
| 歌词 | 歌词框线、字环、字形纹样、文字残影 | 一律 |
| 哥特系列 | 碎玻璃 | 一律（在任何背景都有效，分组只标出它为哪个背景而做；审计 A9） |
| 唱片系列 | 门框地平线、背景线条、立体线条几何、节奏线条碎块 | 一律（同上） |

（帷幕 `@N` 是歌词里的手动触发，不在特效清单里。）

## 7. 字体

### 分组

| 组 | 字体 |
|---|---|
| 黑体 | 思源黑体（粗、中、细、极细）、Chocolate Classical Sans |
| 宋体／明体 | 思源宋体（粗、细）、昭源宋体 HK（粗、细）、Cactus 古典明体、书卷衬线 |
| 圆体 | Zen Maru、昭源圆体（粗、细）、粉圆 |
| 手写 | 霞鹜文楷、芫荽、Klee One、龙藏、Caveat |
| 书法 | 马善政、志莽行、Yuji Syuku |
| 艺术 | Dela Gothic、DotGothic16、站酷快乐、站酷小薇、Zen Antique、Kaisei Decol、Monoton |
| 西文展示 | Fraunces、Playfair、Instrument Serif、Bebas Neue、Space Grotesk、Syne |

（名称依界面现有写法，实现时对照 `src/text/fonts.ts`。）

### 过滤规则

| 规则 | 说明 |
|---|---|
| 判断依据 | 这首歌歌词实际用到的每一个字，对照字体档本身收录的字：`scripts/font-coverage.mjs` 读每个字体所有切片档的字符对应表（cmap），烘焙成 `font-previews/coverage.json`（不用样式表的 unicode-range：中日韩字体共用同一套切片范围，会列出字体其实没有的字） |
| 可完整显示 | 歌词用到的字，该字体全部都有：列在最前面 |
| 部分缺字 | 缺的字会由 Noto 补上：列在「其他（部分文字以替代字体显示）」，并标出缺字比例 |
| 正体与简体 | 不看字体标的「繁中／简中」，只看收录的字；同时收录两者的字体，正体和简体歌词都列为可完整显示 |
| 混合文字 | 中英、中日混合的歌词，每种文字都要收录才算完整 |
| 推荐 | 每个外观和风格各推荐 2～3 个字体，只推荐能完整显示的 |

## 8. 旧设置转换与清理

| 项目 | 处理 |
|---|---|
| 已存的自订主题 | 拆成外观＋最接近的风格＋微调；原本的细旋钮值放进「高级」，画面和以前一样 |
| 各歌曲已存的设置 | 同上，逐首转换，不改变现在的样子 |
| 新歌 | 外观「封面」＋风格「叙事」，菜单上另标推荐风格 |
| 已不用的内容 | 「转向区间」旋钮的残留、旧主题名称（炫酷、电子、温柔、雾光、墨白、切割、平滑）、未使用的内部数值说明文字 |

## 9. 实现范围

| 部分 | 改动 |
|---|---|
| `src/theme/style.ts` | 外观、风格、微调三层的数据结构；旋钮合并；旧数据转换 |
| 推荐 | 新增依节奏分析与歌词密度推荐风格的函数 |
| 字体 | 每个字体的收录表（烘焙脚本）；依歌词过滤与排序 |
| 设置面板 | 外观、风格、微调、高级四区；特效分组与依背景显示 |
| 界面文字 | 六种语言 |
| 不动 | 导演（排版、镜头）、渲染、节奏分析的算法 |
| 测试 | 旧设置转换后画面不变；推荐规则；字体过滤（含正体／简体同时收录的字体） |

## 10. 之后的变动

| 版本 | 变动 |
| --- | --- |
| 3.3.0 | 风格可以带 `engine`：商籁、凝彩（来自 Folia）不经导演，由自己的执行层排版与运镜；外观照样任意搭配。它们的专属设置叫「〈风格名〉的设置」 |
| 3.4.0 | 外观的背景多了 Folia 的五种（通用、隐现、空、莫奈、漫游），名字后面标（Folia）；每种背景有自己的参数 |
| 3.5.0 | 设置分成四个分页：外观、风格、高级、特效。镜头改为登记表（`director/cameras.ts`）：风格只指定镜头 id，任何镜头配任何风格。新增「转场的样子」（柔焦、模糊淡出、淡出、撕裂），和「转场」（何时）分开，属于风格，会存进我的风格。正在播放页的背景可选 Folia 背景 |
