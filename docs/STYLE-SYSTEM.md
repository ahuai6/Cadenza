# 風格系統整理方案（已確認；2.10.0 實作）

## 1. 已確認的決定

| # | 問題 | 決定 |
|---|---|---|
| 1 | 主題拆成「外觀」與「風格」兩層 | 可以 |
| 2 | 六個風格的名稱與適用歌曲 | 不改 |
| 3 | 旋鈕合併為 5 個，細項移入「進階」 | 可以 |
| 4 | 新歌的預設 | 外觀維持「封面」，風格用它原本的動態（＝敘事）；推薦的風格只標「推薦」，不自動套用 |
| 5 | 字體依歌詞過濾 | 可以；**以歌詞實際用到的每個字判斷**，不以「繁中／簡中／日文」標籤判斷。同時支援正體與簡體的字體，兩種歌詞都要列在「可完整顯示」裡 |

## 2. 三層結構

| 層 | 管什麼 | 包含的設定 | 專輯連播時 |
|---|---|---|---|
| 外觀 | 看起來怎樣 | 背景、配色、字體、氛圍與畫面質感特效、封面／影片的呈現方式 | 沿用第一首 |
| 風格 | 歌詞怎麼動 | 鏡頭、歌詞類型、入場、退場、未唱的字、轉場、閃光方式、動態基準值 | 每首各自 |
| 微調 | 在風格上加減 | 5 個旋鈕＋字號；「進階」裡保留全部細項 | 每首各自 |

## 3. 外觀（原五個主題）

|---|---|---|---|---|

| 影片 | 影片 | 思源黑體 | 光點、暗角、顆粒、歌詞框線 | 僅工作坊與綁定 MV 時 |
| 唱片 | 唱片 | 思源黑體 | 門框、背景線條、立體線條、碎塊 | 四個都是專屬特效；純音樂預設 |

## 4. 風格

| 風格 | 鏡頭 | 歌詞類型 | 入場 | 退場 | 適合 | 推薦條件（初稿） |
|---|---|---|---|---|---|---|
| 敘事（新歌預設） | 滑行 | 流動 | 位移飄入 | 淡出 | 中速流行、抒情 | 80–120 BPM，能量中等 |
| 圓舞 | 圓舞 | 流動 | 逐字上浮 | 淡出並上飄 | 慢歌、3/4 拍、溫柔 | 3 拍子，或 < 90 BPM 且能量低 |
| 律動 | 俐落 | 流動 | 衝擊放大 | 淡出 | 快歌、電子、搖滾 | > 120 BPM 且能量高、有鼓 |
| 特寫 | 特寫 | 流動 | 字距收攏 | 淡出 | 說唱、念白、字密 | 歌詞密度 > 每秒約 5 字 |
| 漂浮 | 懸停 | 圓心 | 模糊對焦 | 漸大字距後淡出 | 氛圍、夢幻、後搖 | 沒有鼓或鼓很少，且鋪底音色多 |
| 舞台 | 置中 | 整句 | 逐字上浮 | 淡出 | 純音樂、卡拉OK、MV 字幕感 | 純音樂，或沒有人聲 |

- 推薦用到的資料：速度、拍號、整體能量、鼓聲覆蓋率、人聲有無、歌詞密度（音節／秒）、是否標為純音樂。
- 推薦只在選單上標示，不自動套用；也只推薦一個，同分時取表格中較前面的。
- 各風格的動態基準值（震動、擺動、轉向、縱深……）先取自現在最接近的主題，實作時再逐一調。
- **我的風格**（`app/motions.ts`，存在這台電腦的設定裡）：把目前的動態存成自己的風格——鏡頭、歌詞類型、入場、退場、轉場、未唱字的顯示、動態基準值（`m0`）與字號以外的所有旋鈕（`motionPart`）。在任何一首歌的「風格」選單裡跟內建風格並列，套用時（`withSavedMotion`）外觀與字號不變；樣式記下來源（`motionId`、`motionName`），所以再按儲存會覆寫同一個，也能另存或刪除。改選內建風格就離開自訂風格。

## 5. 旋鈕：13 → 5（＋字號）

| 新旋鈕 | 合併自 | 範圍 |
|---|---|---|
| 速度 | 運鏡速度 | 0.4–1.6 |
| 力度 | 重音力道、重拍觸發靈敏度 | 0–2 |
| 律動 | 律動、文字節奏顫動 | 0–4 |
| 空間 | 空間縱深、漂浮感、轉向幅度 | 0–2 |
| 字感 | 進場時長、光暈與投影 | 0.15–1.6（進場）／0–2（光暈） |
| 字號 | 歌詞字號（跟著專案，不跟著風格） | 0.6–2 |

| 移走的旋鈕 | 去處 |
|---|---|
| 字形紋樣頻率 | 「字形紋樣」特效自己的參數 |
| 殘影色散 | 特效清單，改名「文字殘影」（和畫面的「色散」分開） |
| 全部 13 個細旋鈕 | 「進階」裡原樣保留 |

### 過濾規則

| 規則 | 說明 |
|---|---|
| 判斷依據 | 這首歌歌詞實際用到的每一個字，對照字體檔本身收錄的字：`scripts/font-coverage.mjs` 讀每個字體所有切片檔的字元對應表（cmap），烘焙成 `font-previews/coverage.json`（不用樣式表的 unicode-range：中日韓字體共用同一套切片範圍，會列出字體其實沒有的字） |
| 可完整顯示 | 歌詞用到的字，該字體全部都有：列在最前面 |
| 部分缺字 | 缺的字會由 Noto 補上：列在「其他（部分文字以替代字體顯示）」，並標出缺字比例 |
| 正體與簡體 | 不看字體標的「繁中／簡中」，只看收錄的字；同時收錄兩者的字體，正體和簡體歌詞都列為可完整顯示 |
| 混合文字 | 中英、中日混合的歌詞，每種文字都要收錄才算完整 |
| 推薦 | 每個外觀和風格各推薦 2～3 個字體，只推薦能完整顯示的 |

## 8. 舊設定轉換與清理

| 項目 | 處理 |
|---|---|
| 已存的自訂主題 | 拆成外觀＋最接近的風格＋微調；原本的細旋鈕值放進「進階」，畫面和以前一樣 |
| 各歌曲已存的設定 | 同上，逐首轉換，不改變現在的樣子 |
| 新歌 | 外觀「封面」＋風格「敘事」，選單上另標推薦風格 |
| 已不用的內容 | 「轉向區間」旋鈕的殘留、舊主題名稱（炫酷、電子、溫柔、霧光、墨白、切割、平滑）、未使用的內部數值說明文字 |

## 9. 實作範圍

| 部分 | 改動 |
