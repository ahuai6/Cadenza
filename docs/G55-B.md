# G5.5-B 音频交接与音乐厅

本页记录 G5.5-B 的交付快照。Apple Music 与 LyricsFlow 的后续整合及歌词存储变化见 [G5.5-BR](G55-BR.md)。

## 输出交接

关闭 Hi-Fi 的无声问题涉及两个交接缺口。普通 Web Audio 图在原生独占打开前仍连接系统端点，退出时也没有明确的端点归还。原有设置事务只发出异步重播命令就返回，不能确认新输出是否接管。进度更新因此不足以证明音频已恢复。

`PlaybackCoordinator.handoff` 记录有效时间、播放意图和队列实例，撤销旧输出，等后端完成交接，再以同一队列实例准备新后端。进度和 seek 跟随当前代次。普通端点通过 `AudioContext.setSinkId` 停放和恢复，复用 Gain 和空间声场图。不支持停放的环境使用挂起与恢复。退出 Hi-Fi 等待原生进程关闭，再恢复普通图。同曲交接复用已就绪的视觉会话，保持播放历史和队列实例。用户切歌、暂停和 seek 可以在等待期间更新意图。

隔离 Electron 测试使用前后频率不同的合成片段，Rust 模拟设备检查 seek 后的 PCM，普通输出检查图内频谱。真实 Windows 默认端点另测共享和独占。恢复时间以命令到页面观测运行状态为口径，频谱与 PCM 用于单独确认音频内容。真实原生输出的物理端点、蓝牙和外接 DAC 仍需独立测量。

一次 Windows x64 拆包版测试记录如下。每种方式为单次样本，包含运行状态被测试脚本观测的时间，不能推算 P95 或物理发声延迟。

| FLAC 交接 | 普通 → Hi-Fi | Hi-Fi → 普通 | 原生 seek 到 7 秒后的首次观测 |
| --- | ---: | ---: | ---: |
| 真实 WASAPI 共享 | 215.8 ms | 98.4 ms | 7.0166 s |
| 真实 WASAPI 独占 | 479.2 ms | 430.2 ms | 7.0060 s |

两次真实切回均通过普通音频图信号和往回 seek 的频率验收。隔离的原生模拟设备跨四种格式、两种模式验证输出内容，首个 seek 位置观测相对目标约晚 1.8–17.7 ms。

## 来源能力

| 来源 | 本阶段接通 | 验证边界 |
| --- | --- | --- |
| 网易云音乐 | 公共搜索、推荐、榜单、二维码流程、授权账户和歌单、授权文件路径 | Windows 公网验证公共目录、二维码创建和取消。合成账户验证登录确认、凭据隔离、歌单双重条目、退出和拒绝降档。真实账户扫码、已授权歌单、真实文件保存待验 |
| QQ 音乐 | 公共搜索和官方外部入口 | 公网返回搜索结果，也观察到临时失败。登录、账号歌单、下载未启用 |
| 酷狗音乐 | 公共搜索 | 公网验证搜索。登录、账号歌单、下载未启用 |

| LyricsFlow | 公共搜索、推荐、榜单、歌单详情、歌词及来源明确的 Apple 短试听 | 公网核对目录和试听。文件保存权限待验证，文件服务未启用 |

端点和上游参考见 [在线系统前置研究](ONLINE-RESEARCH.md)。网易云歌单只提交完整分页快照并按账户隔离，读取失败保留上一份完整记录。原始凭据留在主进程，持久化使用系统加密。

## 试听与下载

音乐厅在独立窗口查询和显示结果，主进程负责请求取消、账户和任务。试听使用只在应用内部可读的短期租约。播放协调器交出当前本地输出，复用普通 Web Audio 图。结束、关闭音乐厅及主动操作主播放器时撤销租约。试听不进入曲库、播放历史或队列。

下载只接受允许保存的租约，单队列限制并发。主进程验证 HTTPS 媒体主机与每次重定向，分别处理连接、首字节和流停滞。暂存文件核对长度、编码和时长。Worker 写入标签，以 G5 音频内容指纹和目标标签回读验证。最后通过排他文件提交和增量扫描建立本地曲目及来源关联。支持保留副本或跳过，现有音乐文件不被自动覆盖。导入失败可重试已落地的文件。已提交任务由主进程持有，关闭音乐厅后继续，应用退出时取消运行中的请求。

原词保留实际 TTML 或 LRC 内容。存在独立的译文与音译时，保存为与音频关联的附属来源。在编辑器内可以分别读取和编辑，默认歌词仍选原词。原始时间标记、偏移指令、空行与纯时间戳保留。

## 验证入口

- `node tests/output-handoff-desktop.cjs` 检查 FLAC、MP3、AAC 和 ALAC 的双向交接及频谱、暂停快切、seek。`--real` 启用真实 WASAPI 默认端点。
- `node tests/hall-live-desktop.cjs` 验证公开目录、二维码和试听。该测试访问真实公网，使用隔离配置。
- `node tests/hall-download-desktop.cjs` 验证合成授权响应、提交与入库失败恢复、重复文件、权限拒绝、真实本地播放和歌词保留。测试未使用真实平台账户。
- `node tests/product-desktop.cjs` 检查经典和空间两种入口、窗口隔离、关闭重开、窄窗、键盘和主题。
- 对应桌面测试可配置 `CADENZA_TEST_EXE` 验证本地拆包产物。Windows 运行和基线环境见 [测试说明](TESTING.md)。

后续 G5.5-C 扩展跨平台字段匹配、多轨歌词、差异编辑及 AI 翻译。平台私有能力的实际授权验收、进一步的交互整合和长期资源对照仍需补齐。
