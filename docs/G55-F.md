# G5.5-F 本地播放器、歌词检索与 AI 翻译

Cadenza 聚焦本地播放、高保真输出、歌词、节奏分析和音乐视觉。在线业务入口为按需歌词搜索和 AI 翻译。本阶段保留本地元数据编辑、本地图像选取、已下载的真实音乐文件、可选模型资源和用户资料。下一阶段为 G6。

## 运行边界

- 主应用只有一个播放器。撤销音乐厅窗口和路由、主进程服务与 preload、音乐平台账号和远程歌单、试听协议与播放授权、下载队列及配套 SDK。通用输出事务、普通输出端点停放与恢复、WASAPI 释放确认继续用于本地播放。
- 歌词搜索只返回与本地歌曲关联的文本候选。使用标题、艺人、专辑、时长与可用 ISRC 排序，并提示版本、标题、艺人或时长差异。公开接口之间并行且独立失败。请求取消、连接等待和返回体积均受限。搜索、切歌取消和预览经过主窗口接口。预览不改变永久来源。
- TTML 原文、语言轨、逐字时间及未知节点保留。YRC 与 KRC 的播放视图在解析边界生成，原始文档可保存至各自同名外置格式。现有内嵌标签继续经字段级回读与音频一致性检查。选错目标时按格式拒绝写入，用户可在来源列表选择适用格式。
- 首次读库原子移除已退役的远程曲目与资源关联字段，将历史本地 LRC 偏好写成具体来源。保留曲库条目、音频内容标识、标签和歌词修订、字段来源、歌单、收藏、覆盖、历史及缓存。配置版本与资料代次保持现状。

## 资料收束

仅处理应用资料目录 `library` 下的 `online-accounts.json`、`online-playlists.json`、`online-download-preferences.json`，以及 `credentials/music-<SHA-256>.secret`。目标须通过应用目录真实路径及普通文件检查，目录链接和非文件会跳过并在后续启动重试。AI 密文位于独立 `ai-*.secret` 名称空间。曲库选择的音乐目录和此前下载目录完全不参与清理。窗口会话曾为内存分区，下载任务也不写入应用资料的永久任务表。目录所有权无法证实的外部残余暂存文件保留。对照可使用 `tests/lyric-services.cjs` 内的独立资料和 Windows junction 夹具。

## 歌词上游

| 来源 | 主进程契约 | 范围 |
| --- | --- | --- |
| LRCLIB | 匿名 `/api/search` | 逐行或增强 LRC、纯文本 |
| LyricsFlow | 匿名 `/lyrics/by-metadata` | TTML、LRC 或纯文本，来源未报告匹配信息时降序并提示。只访问歌词接口 |
| AMLL | 使用已查询的网易云、QQ 或 Apple 目录曲目标识，从上游对应目录读取 TTML | 歌词仓库未收录的歌曲正常跳过 |
| 网易云 | 匿名歌曲 ID 查找及歌词接口 | LRC、YRC，及接口确实返回的译文、音译 |
| QQ 音乐 | 匿名歌曲搜索建议、公开歌词接口 | LRC 与实际返回的附属轨。公开入口未证实可取得 QRC |
| 酷狗 | 匿名歌词正文搜索及候选读取 | 有界解包和重封装 KRC；保留原时间与语言数据。结构完整时可查看译文和音译 |

上游地址和解析集中于 `electron/lyric-service.cjs`，生产构建不访问这些服务。协议修改先用合成响应回归，再使用公开样本观察 HTTP 状态、格式、时间精度和是否带有语言轨，验证过程不保存商业歌词。非官方接口可能退化或限速，来源错误不影响本地播放。 [LRCLIB API](https://lrclib.net/docs) · [LyricsFlow OpenAPI](https://api.trylyricsflow.com/openapi.json) · [AMLL 歌词仓库](https://github.com/amll-dev/amll-ttml-db)

## AI 授权与翻译

用户在歌词编辑器展开 AI 设置。ChatGPT 使用系统浏览器、官方动态客户端注册、短时回环端口、随机 state、PKCE S256 和 OIDC nonce。主进程根据官方 JWKS 验证签名、签发者、受众、有效期及 nonce，再保存账户会话。直接推理须持有单独的 `chatgpt.tokens.use.direct` 授权。刷新与轮换串行，退出清本地会话并请求撤销，远端撤销失败会明确提示。 [官方登录](https://developers.openai.com/siwc/token-sharing-open-source/sign-in) · [直接推理](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference) · [预览限制](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations)

OpenAI 官方 API Key 使用 Responses 流。DeepSeek 使用官方 Chat Completions JSON 输出与 SSE，默认采用 `deepseek-flash`。兼容服务可独立设置名称、HTTPS Base URL、协议、密钥、模型、目标语言和超时。模型列表探测按需发起，并可手工录入模型标识。官方凭据始终绑定官方地址，自定义地址变更需重新提供密钥，禁止带授权请求重定向。配置记录与系统加密的凭据分开。 [DeepSeek 流式契约](https://api-docs.deepseek.com/api/create-chat-completion)

AI 接收用户选定的行、当前歌曲文本上下文和翻译要求。整首、选定范围或补缺使用按当前修订绑定的行 ID。任务取消、切换曲目或来源、编辑原文都会撤销旧结果。服务返回完整流末端与合法行 ID 后，先提供可修改译文，用户确认后应用至草稿，再显式保存至 TTML。仍有原生逐字标记的译文需要手动结构化编辑。超时、限速与额度错误会显示，已发起的翻译由用户决定是否重试。LRC、YRC、KRC 或纯文本的 AI 译文可进入独立附属草稿，已有外置译文或草稿会保护，原歌词不作格式转换。系统未取得真实账户或有效 API Key 时，应使用隔离的合成授权和 SSE 测试验证客户端。实际账户配额、地区、工作区许可及模型推理需独立验收。

## 验证入口

- `node --test tests/lyric-services.cjs` 验证不同 API 协议、签名及刷新轮换、流式终止、行 ID、取消、版本匹配与资料清理。
- `node tests/product-desktop.cjs` 和 `node tests/lyrics-desktop.cjs` 验证 Windows Electron 界面与权限、歌词字段、草稿工作流和重新读取。测试使用合成音频、合成翻译与隔离资料。
- `node tests/output-handoff-desktop.cjs` 检查普通图内频谱和原生模拟 PCM，`--real` 覆盖默认 WASAPI 共享与独占。设备物理 DAC 发声时间须另外测量。 [原有交接证据](parts/engine.md#g55-b-本地输出交接)

## Windows 验收记录

- Windows x64、Electron 45.1.0。隔离启动拆包 EXE，经典和空间界面通过编辑权限、唯一窗口、本地播放及资料清理回归。歌词端到端通过模拟兼容服务配置、模型发现、流式翻译、人工修订、TTML 内嵌和独立 LRC 附属轨。应用译文到草稿时，音频文件散列保持原值。保存后回读目标字段并比较音频内容身份。
- 公网探针取得 LRCLIB 的逐行和纯文本、LyricsFlow 逐字 TTML、网易云逐行及 YRC 与附属译文、QQ 公开逐行 LRC、酷狗 KRC。AMLL 已知公开 TTML 直链返回有效 XML，按搜索歌曲 ID 查询时也观察到未收录的 404。真实账号、调用配额、QQ 公开 QRC 和公网 KRC 附属语言内容仍需按样本核对。
- Windows 默认设备 FLAC 实际交接中，共享与独占切回普通输出均重新取得图内信号，且 seek 后的频率区间正确。切回状态观测时间分别为 113.7 ms、430.4 ms，原生 seek 到 7 秒的首次观测为 7.0066 s、7.0058 s。每种设备模式一轮。另用模拟 PCM 覆盖 FLAC、MP3、AAC、ALAC 的两种原生模式。未测量物理 DAC 或蓝牙端点输出。
- 基准为 BR2 的已构建产物，对照以相同 NSIS 目标从原拆包目录重打。NSIS 安装包体积为 382,246,786 → 380,366,670 字节，`app.asar` 为 163,246,938 → 154,178,327 字节。锁文件直接运行时依赖为 7 → 5，全部条目为 549 → 478。最终 ASAR 核对未含音乐厅 preload、旧下载、试听和平台 SDK。
- `tests/baseline/g55f-startup.cjs` 每次使用全新隔离资料，记录启动后 1.5 秒内的 Chromium NetLog 与进程私有内存。基准和收束快照每组三次，未发现旧音乐平台启动请求，两边均观察到 Chromium 自带的两条 `gvt1.com` 请求。同批快照主进程私有内存中位数为 102,028 → 99,592 KiB，Renderer 为 167,872 → 164,808 KiB。这是空曲库小样本观测，不能推断日常播放的稳定性能收益。
