# Cadenza 文案与命名

界面上出现的每一个字都从这里来。这份文档有三个部分：写法、词汇表、目前已知要改的地方。

状态：**初稿**。词汇表记录的是 3.0.5 界面上实际在用的词，加上已经确定的取舍。标成「待定」的项目会在第 3 阶段（新设计语言）连同整个界面一起定案，定案前不要自己挑一个用。

## 简体文档与繁体界面的对照

这份文档以简体中文与大陆惯用词书写；界面实际显示的字以 `src/i18n/dict.json` 为准。繁体界面（zh-Hant）里同一个词的写法：

| 文档里 | 繁体界面 | 文档里 | 繁体界面 |
| --- | --- | --- | --- |
| 播放队列 | 播放佇列 | 设置 | 設定 |
| 导出（视频） | 匯出（影片） | 高级 | 進階 |
| 默认 | 預設 | 窗口／小窗口 | 視窗／小視窗 |
| 菜单 | 選單 | 文件夹 | 資料夾 |
| 界面 | 介面 | 用户 | 使用者 |
| 显卡 | 顯示卡 | 缓存 | 快取 |
| 数据 | 資料 | 图标 | 圖示 |

简体界面（zh-Hans）的用词也以字典为准，改词时三处一起看：这份词汇表、`zh-Hant`、`zh-Hans`。

## 1. 写法

**说用户得到什么，不说程序做了什么。**
「播放时不卡顿」是用户得到的；「预先绘制字形与转场」是程序做的。标题用前者，后者最多放在说明里，而且只在「高级」出现。

**一个东西一个名字。**
同一个东西在菜单、按钮、提示、设置页、说明文字里用同一个词。要换词就全部一起换，并且先改这份表。

**按钮写动作，动作写结果。**
按钮是动词开头（「加入歌单」），做完的提示说发生了什么（「已加入『雨天』」），两边用同一个词。

**不用需求描述里的临时名称。**
讨论功能时随口叫的名字（「空间模式」「极客感」「小窗」）不是产品用词。一个新东西要上界面，先在这里取名。

**专业内容放在专业的地方。**
算法名称、模型名称、技术参数只出现在「高级」与诊断信息里。一般设置页看不到「神经网络」「缓存」「帧」这类字。

**语气。**
平实、简短、不卖弄。不用惊叹号，不用「哦」「啦」「～」，不拟人，不道歉连发。错误消息说三件事：发生了什么、数据有没有受影响、现在可以做什么。

**标点与格式。**
中文用全角标点；中文与英数字之间空一格（「导出 MP4」）。「…」用一个字符，只加在按下去还会再问一次的动作后面（「导出视频…」）。

**各语言各自写。**
其他语言不是逐字翻译：先确定这句话要让人知道什么，再用那个语言自然的说法写。英文用英式拼写（favourite、colour）。

## 2. 词汇表

格式：**正式用词**（英文）— 指什么。「不用」列的是曾经出现或容易混用的说法。

| 桌面歌词 | Desktop lyrics | 浮在所有窗口之上的三行歌词（自己的窗口）；「锁定」后鼠标穿过它 | 浮动歌词、悬浮歌词 |

### 特效歌词的风格

风格决定歌词怎么排、怎么动；外观（背景、颜色、字体）另外选，任何外观配任何风格。

| 用词 | 英文 | 指什么 |
| --- | --- | --- |
| 叙事、圆舞、律动、特写、漂浮、舞台 | Story, Waltz, Groove, Close-up, Float, Stage | Cadenza 自己的六种（导演排版与运镜） |
| 商籁 | Sonnet | 来自 Folia 的风格：每段歌词是一幅平面设计版面（直排栏、大字、拼贴、色带、海报色块），配线稿、参考线与画框标记，段落之间模糊、故障或拉镜转场 |
| 凝彩 | Tempera | 来自 Folia 的风格：大片色块、挖空与排线，字在色块上反相；段落之间色块扫过，鼓点时墨迹晕开 |
| 画面处理 | Finishing | 整个画面最后一道处理（颗粒、网点、色偏、暗角、镜头弧度）；不叫「后制」「后处理」。商籁、凝彩各有自己的一份，也是一个任何风格都能用的特效 |

| 版面标记 | Layout marks | 商籁画面四周的线框与标记，拆出来当成任何风格都能用的特效 |


| 通用、隐现、空、莫奈、漫游 | Common, Latent, Sora, Monet, Nomand | 来自 Folia 的五种背景，在「外观 → 背景」里和 Cadenza 自己的背景并列，名字后面标（Folia）；颜色只取外观的颜色与封面的颜色，不用 Folia 生成的主题色 |
| 点阵、波纹玻璃、纸纹、网点、镜头 | Dither, Fluted glass, Paper, Halftone, Lens | 漫游背景处理封面的五种效果 |
| 用 Folia 自己的分词 | Use Folia’s own word split | 商籁、凝彩的风格设置：改用 Folia 的自动分词，不用 Cadenza 的分词与自订分词 |
| 盖上底色 | Veil | 在背景上盖一层外观的背景色，让歌词更清楚；不叫「遮罩」「覆盖层」 |

| 柔焦、模糊淡出、淡出、撕裂 | Soft focus, Blur out, Fade, Tear | 「转场的样子」：段落之间画面怎么过去。柔焦是 Cadenza 自己的；后三种来自 Folia 的商籁，名字后面标（Folia）。什么时候转场仍由「转场」决定 |
| 镜头与细项 | Camera and details | 「高级」分页里镜头、转场、入场退场与每一个旋钮的那一节 |

外观与风格的设置分成四个分页：**外观**（外观、背景、颜色、字体）、**风格**（内置风格与我的风格）、**高级**（〈风格名〉的设置、微调、镜头与细项）、**特效**。分页名称就是这四个词，不另取名字。

风格的专属设置一律叫「〈风格名〉的设置」，放在风格的「高级」里；画面处理放在「特效」。

### 空间界面的房间

房间的名字只是地点，不带宗教或建筑术语。代码里的标识符：`gallery`（长廊）、`atrium`（中庭）、`lists`（收藏室）、`listening`（聆听室）、`settings`（工作室）（3.2.1 起，取代旧的 `nave`、`dome`、`altar`）。

| 用词 | 英文 | 放什么 |
| --- | --- | --- |
| 长廊 | Gallery | 专辑 |
| 中庭 | Atrium | 全部歌曲 |
| 收藏室 | Collection room | 歌单 |
| 聆听室 | Listening room | 正在播放的歌 |
| 工作室 | Studio | 设置 |

空间里的对象：**收音机**（Radio）——中庭水池边那台可以拿起来的音源；动作是「拿起来」「放下」。

## 3. 已知要改的地方

已处理（3.1.2）：

- 「重新扫描」只指重新读取文件夹；重新读一首歌的节奏叫「重新读取节奏」，提示也用同一个词。
- 动作是「加入收藏／取消收藏」，那张清单是「收藏」。
- 「播放清单」统一为「歌单」，「歌曲库」统一为「音乐库」。
- 设置里的技术词改成说结果的名字（3.1.3）：节奏识别→读取节奏、引擎→读取方式（精确／快速）、分析时机→新歌何时开始、预先绘制→先准备接下来的画面、画质模式→画面效果（完整／省力／最省力）、清除所有缓存→清除临时数据。

- 空间界面的字符串并进主字典（`sp.` 开头的键），`ts()` 只是读它们的简写；空间设置卡的字段改由设置纲要产生（3.1.4）。
- 「清除所有数据」的说明不再出现「缓存」（3.1.4）。

还没处理：

1. **说明文字太长**：性能与调试类（用显卡绘制歌词、显示性能数据、详细调试日志）的说明还是实现细节。
2. 主字典与 `sp.` 之间仍有意思相同的词（例如 `sp.q.mid` 与 `sp.line.mid`），重建空间时一起整理。


## 4. 怎么加一个新词

1. 先查词汇表：这个东西是不是已经有名字。
2. 没有的话，在这份文档加一列（用词、英文、指什么、不用哪些说法），再写进字典。
3. 动作的名字写在指令里（`src/app/commands/`），设置的名字跟着设置纲要（`src/app/settings/schema.ts`）；菜单、按钮、提示都从那里取，不在画面组件里另外写字。
