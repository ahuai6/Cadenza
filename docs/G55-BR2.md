| 平台 | 本轮实现与证据 | 范围和限制 |
| --- | --- | --- |
| 网易云音乐 | 对当前搜索结果的专辑 ID 读取公开专辑。Windows 公网查询专辑 `172276` 得到 18 首。下载资源保留原生 YRC，并同时提供来源有返回时的原始 LRC、译文和音译。YRC 播放按原始毫秒时间渲染。 | 原有账号下载的真实授权文件未复测，新增下载尚未接通高解析度或可安全试听的短片段端点。 |

### LyricsFlow 文件服务的实际阻碍

技术端点存在。OpenAPI 2.0.0 公布直接文件与转换端点，`/api/music/audio-traits` 的独立探测返回 HTTP 200，公开了音质属性。现场请求 `/status` 也返回 HTTP 200，并明确把流和直下描述为服务端解密，列出 gamdl、Widevine 和 FairPlay 解密服务。因此没有发起文件端点取流。本轮没有找到服务条款明确允许、且不经过该保护规避链路的直接分发端点或测试资源。

将来若服务方提供独立合法分发路径，可以从受审核适配器发出保存租约并走现有下载器。媒体接收功能仅证明字节、格式和文件写入能力。目录音质、转换格式和实际文件授权分别核对。 [LyricsFlow 服务协议](https://api.trylyricsflow.com/openapi.json) · [运行状态](https://api.trylyricsflow.com/status)

### 使用自有 Apple 配置复核

1. 从自己的 Apple Developer MusicKit 配置取得 Developer Token。若只配置公共目录，将其写入本机 JSON 的 `developerToken`，然后在音乐厅账号页选择「导入 MusicKit 授权」。
2. 私人歌单另需通过同一自有 MusicKit 应用取得经过用户同意的 Music User Token。与 Developer Token 一起放入所选 JSON，字段名为 `musicUserToken`。之前导入的 Developer Token 可复用。不要将真实文件放进 Cadenza 仓库。
3. 导入成功后，在 Apple Music 标签选择该账号并同步歌单。从个人歌单进入曲目，只有带官方目录映射的曲目会显示可用的目录试听路径。退出移除本地凭据和对应快照。 [MusicKit 用户认证](https://developer.apple.com/documentation/applemusicapi/user-authentication-for-musickit)

## 受管下载与设置

下载器从受信任的主进程适配器获得允许媒体域名和封面域名。每一跳重新验证 HTTPS、来源和到期时间，不发送账号 Cookie，不接受 Renderer 提供的远程 URL。网易云是当前具有受管保存接口的平台。异域名合成测试验证合法媒体能走完入库、越界重定向和仅试听租约会被拒绝。完成状态在暂存文件清理后提交。

音乐厅下载任务页增加全局设置、按平台的部分覆盖和恢复继承。单次下载显示已有偏好、来源实有质量、文件名预览及可展开的写入选项。用户可以选择目录、音质偏好、三种命名、跳过或保留同名副本和是否入库。现有目录偏好可读取，目录继续由系统选择器授予。批量下载和可配置并发尚未实现。

| 内容 | 本轮写入及回读边界 |
| --- | --- |
| 可选元数据 | TagLib 适配曲名、艺人、专辑、专辑艺人、曲序及总数、盘序及总数、年份、流派、作曲、版权、ISRC 和封面。仅在可信资源返回且音频原字段为空时填入。FLAC 端到端验证曲名主动填入、未选专辑保持空白。UPC、作词及完整发行日期未新增写入。 |
| FLAC 主歌词 | 原生 YRC、来源 LRC 或 TTML。真实文件用可发现的 YRC、LYRICS 或 TTML 字段。选内嵌、外置或两者。本地合成下载后用新资料扫描回读 YRC 和译文。 |
| MP3 / AAC / ALAC 主歌词 | 沿用 ID3 USLT 或 MP4 `©lyr`，保存确切源文本。现有 ALAC/TTML 标签回写有独立回归。新组合未逐个完成端到端文件写入。 |
| 语言轨 | 可单独选择已有译文和音译。FLAC 使用独立内嵌字段，其他格式的独立辅助轨沿用可发现的同目录来源。原生 TTML 内已有语言轨随文档原样保存，未推断、删除或重新匹配嵌套轨。 |

没有生成来源缺失的 LRC、译文或音质。明确选择来源 LRC 时，如原生歌词存在而服务无 LRC，任务报告无法取得该格式。没有启用未验证的 QRC/KRC、TTML 转换或增强 LRC 转换，也未引入 AI 翻译。YRC 存储保留原文，播放转换单独进行，并按相同偏移校正音节的起止时间。

## 可重复的上游与 Windows 验证

`npm run online:upstream` 继续检验 QQ SDK、网易云参考 SDK、酷狗 HEAD 和 LyricsFlow OpenAPI，并增加 QQ 搜索建议、QQ 专辑及歌词、酷狗推荐和榜单分页、网易云专辑的真实适配器探测。当前 QQ 包 2.6.0 精确锁定。酷狗移动站契约由本地独立适配器维护，未将 Android SDK 或研究仓库打包。版本变更先告警并复测，普通构建仍只运行离线 `online:verify`。

最终本机抽测通过 TypeScript、Vitest 43 个文件共 397 项、在线契约 8 项，以及歌词、ALAC、经典和空间模式的桌面回归。下载用例验证受管的非网易云测试主机、重定向拒绝、FLAC 内嵌与外置 YRC、译文、字段选择及新资料回读。最终拆包版公网测试验证四平台公开查询、新增榜单及专辑、Apple Music 短试听和退出后的本地播放恢复。另有一次在线验收在 Apple 公共目录超时，随后同口径复测通过。

最终拆包版通过真实 Windows WASAPI 默认端点共享和独占交接。单次 FLAC 切回普通输出至观察到运行状态分别约 163 ms 和 319 ms，图内的 seek 后频段也吻合。此指标不代表物理音频端点延迟或长期稳定性。
