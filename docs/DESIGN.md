# Cadenza 设计语言：舞台

第二版（3.1 起）。取代先前的「Liner Notes」。这份文件是介面的规则书：先讲想法，再讲数值，最后讲怎么用这些积木拼出新画面。数值都在 `src/app/styles/tokens.css`，元件在 `src/app/ui/`；文件与程式不一致时，先改文件再改程式。

## 1. 想法

Cadenza 是功能完整的播放器，音乐库、播放、歌词、特效歌词、工坊各有份量；介面的结构要让它们并存而不杂乱，并让「正在听的这首歌」始终是视觉的重心：

**正在播放的歌就是舞台，其他东西都是暂时走上舞台的道具。**

- **首页是「正在播放」**，不是音乐库。打开程式看到的是这首歌：封面、歌名、歌词，整个视窗染上封面的颜色。
- **音乐库是一张纸**，从下方升起盖在舞台上；舞台退后、变暗，但还在。放下这张纸就回到歌。
- **播放控制是舞台的台口**：永远在最下面一条，两种状态下都是同一条，不会换位置。
- **专辑站在一条线上**：这条线同时是进度与节拍的线（见第 6 节）。

由此得到四条判断标准，设计任何新画面时依序问：

1. **它属于这首歌，还是属于音乐库？** 属于歌的放在舞台上，属于库的放在纸上。不新增第三种地方。
2. **它的颜色从哪来？** 从封面来。介面自己不带彩色；需要强调时用这首歌的颜色。
3. **它在动的话，跟着什么动？** 跟着手（使用者的操作）或跟着音乐（拍点、歌词时间）。没有第三种理由的动画不做。
4. **一般人需要看到它吗？** 不需要的收进「进阶」。技术名词不上主画面（见 `docs/COPY.md`）。

## 2. 颜色

**一首歌一个色相。** 播放中的歌的封面决定色相（引擎的调色盘 `session.ambient`），外壳把它写成 `--song-h`（色相）与 `--song-c`（彩度系数）。没有歌时是暖灰（色相 30、彩度 0.25）。

| 角色 | token | 深色 | 浅色 |
|---|---|---|---|
| 舞台底 | 引擎画的环境色场 | 封面色的流动色场 | 同左（舞台永远是深的） |
| 纸（音乐库的底） | `--bg` | 这首歌色相的极深色（明度约 12%） | 这首歌色相的极浅色（明度约 95%） |
| 文字 | `--fg` / `--fg-2` / `--fg-3` | 象牙白与两级灰 | 墨与两级灰 |
| 选中、主要动作 | `--pick` / `--on-pick` | 象牙白底、墨字 | 墨底、象牙白字 |
| 这首歌的颜色（正在播放的标记、进度、连结） | `--accent` | 色相的亮调（明度约 76%） | 色相的深调（明度约 36%） |
| 危险 | `--danger` | | |

规则：

- **选中用反白，不用彩色。** 分页、分段控制、主要按钮选中时是「纸的反色」；彩色只留给「这是正在播放的歌」。
- 换歌时颜色在 1.2 秒内过渡，不跳。
- 文字对底色的对比至少 4.5:1；`--fg-3` 只用在 24px 以上的字或非必要资讯。
- 舞台上的东西用 `.on-picture`（白字、深色毛玻璃）；纸上的东西用一般 token。同一个元件两边都能放。

## 3. 字

- 一个字族：介面字体（预设 Instrument Sans＋思源黑体），标题只是更重、更大，不换字体。设定里可换（`uifont.ts`）。
- 字级只有七级：

| token | 大小／行高 | 字重 | 用在 |
|---|---|---|---|
| `--type-hero` | 44/1.05 | 700 | 纸的大标题（「音乐库」） |
| `--type-title` | 34/1.15 | 700 | 舞台上的歌名 |
| `--type-lyric` | 38/1.3 | 700 | 舞台上的歌词（依视窗缩放） |
| `--type-head` | 22/1.25 | 650 | 区块标题、卡片标题 |
| `--type-body` | 16/1.45 | 450（强调 600） | 列表标题、内文、按钮 |
| `--type-note` | 14/1.4 | 450 | 副标、说明 |
| `--type-tiny` | 12/1.3 | 550 | 数字、时间、标签 |

- 数字用等宽数字（`tabular-nums`）。不用全大写加宽字距的小标签（上一版的 kicker 取消）。
- 一行放不下的歌名不截断成「…」，用跑马灯（`ui/Marquee`）。

## 4. 形状与间距

**圆角四级＋胶囊**，依「东西有多大、浮不浮」决定：

| token | 值 | 用在 |
|---|---|---|
| `--r-1` | 10px | 列表里的封面、标签、小块内容 |
| `--r-2` | 14px | 输入框、选单项目、列表的一列、网格封面 |
| `--r-3` | 20px | 浮起来的：选单、弹窗、面板、舞台上的大封面 |
| `--r-4` | 28px | 纸（只有上面两个角） |
| `--r-pill` | 999px | 所有按钮、分页、分段控制、开关 |

巢状时内层取「外层减间距」。**封面永远完整显示、不裁切**：容器跟着封面的比例走，不是把封面塞进固定的方格。

**间距**用 4 的倍数：4、8、12、16、24、32、48、64、96。页面左右留白：纸 56px，舞台 104px（视窗窄于 1100px 时各减半）。

**可点的东西至少 44×44px。** 图示按钮是 44px 的圆；图示本身 20px、线宽 1.8。

**表面**只有三种：

1. 舞台：没有边、没有底，直接在色场上。
2. 纸：实色、上缘圆角 28px、往上投一道柔和的长阴影。
3. 浮层（选单、弹窗、伫列、设定抽屉）：圆角 20px、毛玻璃或实色、一道阴影。

列表不画格线、不用卡片；一列在滑过时才出现圆角底色。

## 5. 动态

**一条曲线**：`--ease`＝`cubic-bezier(0.16, 1, 0.3, 1)`，先快后慢。可以被打断的大动作（纸的升降）用弹簧（`motion.ts` 的 `Drive`），中途反向不会跳。

| token | 时长 | 用在 |
|---|---|---|
| `--t-fast` | 120ms | 滑过、按下的回馈；任何东西离场 |
| `--t-med` | 220ms | 选中状态改变（分页、开关、图示按钮） |
| `--t-enter` | 320ms | 一块内容进场（淡入＋上移 8px） |
| `--t-stage` | 620ms | 纸升降、舞台退后、抽屉滑入 |
| `--t-song` | 1200ms | 换歌时的颜色过渡 |

规则：

- **离场比进场短**，新旧两层不叠在一起。
- **纸升起时舞台同时退后**：缩到 0.9、上移 36px、变暗到 18%。这是同一个动作，共用一个进度值，不分两段。
- **列表进场**每列延迟 16ms，最多 12 列，之后一起出现。
- **歌词等待时是三个点**（前奏或四秒以上的间奏）：随等待的进度由左到右亮起，跟着歌曲时间，不是循环动画；这时下一句歌词已经淡淡地在它的位置上，开口时只是变亮，不是跳出来。
- **跟着音乐的动态**（节拍线上的脉动、封面的呼吸）只在播放时动，幅度小于 4%，并遵守「减少动态」设定。
- 「减少动态」开启时：所有位移改成淡入淡出，弹簧直接到位。

## 6. 节拍线（专辑）

专辑不是网格，是站在一条横线上的一列封面。

- 线在纸的中段偏下，横贯整张纸；线下方有细刻度。
- 封面底边贴着线，一张接一张；选中的那张在正中央、放大 1.5 倍，其余半透明。点任何一张，整列滑动让它到中央。
- 线的上方是选中专辑的名字与演出者；线的下方是它的曲目。
- 播放的专辑正是选中的这张时，线从左边开始被这首歌的颜色填满到目前进度，进度点上有一圈跟着拍点扩散的环。
- 滚轮与左右键移动选择；两侧淡出。点选中的那张（或按 Enter）就播放。
- 专辑依开头字母排（英文字母、中文的拼音首字母、假名的罗马字首字母，其余在 #），十二张以上且不只一个字母时，线上方有一排字母，点了跳到那个字母的第一张。

## 7. 积木

新画面用这些拼，不另外发明。全部在 `src/app/ui/kit.tsx`（除非另注）。

| 积木 | 是什么 | 规则 |
|---|---|---|
| `Pills` | 一排胶囊分页／分段控制 | 选中是反白；最多 6 个，更多改用选单 |
| `Button` | 胶囊按钮 | `kind`：`solid`（反白，一个画面最多一颗）、`ghost`（细边）、`danger` |
| `IconButton` | 44px 圆形图示钮 | 一定有 `label`（提示与无障碍名称） |
| `Row` | 列表的一列：封面、两行字、尾端资讯 | 封面 56px；整列可点；右键是指令选单 |
| `Cover` | 封面 | 不裁切；没有封面时是这首歌色相的色块加音符 |
| `Sheet` | 纸 | 整个程式只有一张 |
| `Drawer` | 从右侧滑入的抽屉（歌曲设定） | 宽 420px；背后是可点击关闭的暗幕 |
| `Toggle` / `Slider` / `Select` | 设定用的控制项 | 由设定纲要产生（`settings/schema.ts`），不手写 |
| `Disclosure` | 「进阶」折叠 | 预设收起；里面才可以出现技术名词 |
| `Marquee` | 太长的字 | 取代「…」 |

**一个动作只有一个入口定义**：按钮与选单的名称、图示、行为都来自指令登记表（`src/app/commands/`）。

**新增一个画面的步骤**：

1. 用第 1 节的四个问题决定它放在舞台还是纸上。
2. 用上表的积木排出来；缺积木时先在这份文件加一列，再写进 `ui/`。
3. 颜色、圆角、时长只用 token（`tests/unit/arch.test.ts` 会挡字面值）。
4. 文字先过 `docs/COPY.md`。
5. 在 `tests/desktop.cjs` 加一段检查。

## 8. 版面

| 位置 | 规则 |
|---|---|
| 顶列 | 高 56px，浮在一切之上：左边品牌名，正中央导览胶囊（正在播放／音乐库／海报墙／歌词工坊），右边设定与视窗按钮 |
| 台口（播放列） | 高 96px，最上缘一条 3px 进度线横贯视窗；左边小封面与歌名（只在纸升起时出现），正中央播放控制，右边伫列、音量、收藏 |
| 舞台 | 顶列与台口之间。左边封面（中心在视窗 ¼ 线上）与歌名，右边歌词从 ½ 线开始 |
| 纸 | 上缘在顶列下方 16px，下缘贴着台口。标题列：大标题在左，分页胶囊在右；内容可卷动 |
| 设定 | 纸上的一页：常用的在上面，节奏、画面、资料在最下面的「进阶」里（开过会记得）。待做：由设定纲要产生 |

## 特效歌词与「外观与风格」页

- 特效歌词画面四周的黑边与转场的染色，用封面色调的深色，和正在播放页一致。
- 控制列与侧边面板用与正在播放页相同的深色毛玻璃与圆角。控制列一行排完：播放方式、上一首／播放／下一首、进度、时间、音量、其余按钮。
- **外观与风格页**（特效歌词与歌词工坊共用，3.5.0）：最上面一排四个胶囊分页——外观、风格、进阶、特效；选中反白，记得上次开的。外观和风格任意搭配；技术名词只在「进阶」出现。风格用卡片呈现，每张卡片画出它的镜头路径；推荐的那张有标记。微调滑杆在 1.00× 处有刻度，调离时轨道与数值改用强调色。各分页的内容见 `docs/parts/app.md`。

## 字体档

- 字体登记在 `src/text/fonts.ts`（歌词）与 `src/app/uifont.ts`（介面），按风格分为细、粗、衬线、手写、艺术几类。
- 所有字体都是 SIL OFL 1.1，允许随程式发布，因此全部打包在 app 内，不必线上下载。
- 选用之前会先载入要显示的字（`ensureFont` 会预先载入歌词用到的字），换字体时不会先闪一下别的字体。

## 9. 设计方向的选择纪录（3.1 之前）

第 3 阶段开始前，做了三个可以点的原型让使用者选（2026-11，设计划布「Cadenza 设计方向」）。三者都要回答同一件事：「不像普通播放器、整体感、去掉工具感」。

| | 方向 | 核心想法 | 结果 |
| --- | --- | --- | --- |
| A | 舞台 | 「正在播放」就是首页，整个视窗跟着封面颜色流动；音乐库是从下方升起的一张纸 | **采用**为主方向（本文件第 1–8 节） |
| B | 书页 | 既有纸感风格的进化：浅色、大标题、目录式列表，右侧固定一栏正在播放；歌词展开时整页翻成深色跨页 | 没有采用；留作参考，见下 |
| C | 节线 | 一条横线贯穿视窗，同时是进度条与节拍线；封面站在线上排成一列 | 用在**专辑页**（第 6 节） |

### 方向 B：书页

原型原始码保存在 `docs/design/direction-b-book.dc.html`（设计划布的格式，需要画布的执行环境才能操作；画面里的歌名、演出者、歌词都是自己编的假资料）。它没有被选上，原因是改变最小、最像一般播放器；但它是三者中**最稳、最好读**的一个。之后若要做「阅读感重于舞台感」的地方（例如浅色的资料页、说明页、列印或汇出的歌词页、低动态模式），从这里取材，并照下面的规格。

**想法**：音乐库是一本书。每个分页是一章，列表是目录；正在播放的歌是书页旁固定的一栏；要专心看歌词时，整页翻成深色的跨页。

**颜色**（只有四个，加一个强调色；不随封面变色，这是它和「舞台」最大的不同）：

| 角色 | 值 |
| --- | --- |
| 纸 | `#F3F1EC`（暖白） |
| 墨（文字、选中、主要按钮底） | `#1D1B18` |
| 次要文字 | `#5F5A52` |
| 强调（正在播放的那一列、连结） | `#A03D18`（陶土色），滑过 `#7C2E10` |
| 线 | 墨色 10%–14% 透明度的细线；滑过的列底色为墨色 5% |
| 跨页 | 底 `#1D1B18`、字 `#F3F1EC`，次要字 72% 透明度 |

**字**：标题用衬线（Noto Serif TC，900），内文用无衬线（Noto Sans TC 400／500／700）。字级：章名 72px（行高 1）、跨页歌词 40px、跨页歌名 36px、侧栏歌名 28px、品牌 24px（衬线斜体）、侧栏目前歌词 22px、内文 14–17px、小字 13px。

**版面**（1440×900 为准，可换行收窄）：

- **顶列**高 88px，下缘一条细线：左边品牌「Cadenza」与章节分页（歌曲、专辑、歌单、设定；选中的字变粗并在下方画 2px 墨线），右边一颗细边胶囊「展开歌词」。左右留白 56px。
- **主栏**（弹性 999、最小 560px，内距 48／56／56）：章名 72px 大标，旁边一行小字的统计（「7 首 · 27 分钟」）。
  - 歌曲：目录式列表，每列网格 `28px 60px 1.5fr 1fr 56px`——序号（正在播放的改成 ▸ 并用强调色）、封面、歌名与演出者、专辑、时长；列之间一条细线，没有卡片。
  - 专辑：`minmax(200px, 1fr)` 自动填满的网格，方形封面圆角 6px，间距 36／28px。
  - 歌单：最多 640px 宽的一栏，每列「名称 … 首数」，下面一颗细边胶囊「新建歌单」。
  - 设定：最多 640px 宽，每项一列（至少 68px 高），右侧是开关；最下面一列「进阶」可展开，里面才有输出装置、节奏分析、诊断。
- **侧栏**（正在播放，380–460px，右侧内距 56px）：方形封面（圆角 8px、柔和长阴影），歌名与演出者 · 专辑，收藏的心，一条 2px 的进度线，播放键（56px 墨色圆）与上一首／下一首（48px），三个外观图示（封面的颜色、唱片、影片；选中时墨底反白），最下面是目前这句歌词（22px 衬线）与下一句（15px 次要色）；前奏时是三个依序亮起的点。
- **跨页**（按「展开歌词」）：一张深色的页从右边滑入盖住整个视窗（640ms，`cubic-bezier(.2,.8,.2,1)`）。左半是大封面与歌名，右半是 40px 的衬线歌词，唱过的与未唱的以透明度区分（520ms 过渡）；右上一颗「收起」胶囊。

**动态**：只有三种——列表进场淡入并上移 10px、跨页滑入滑出、歌词与封面颜色的淡变（400–700ms）。「减少动态」时全部关掉。

**和「舞台」的关系**：按钮一律胶囊、可点范围至少 44px、选中用反白、技术词收进「进阶」，这些规则两者相同；不同的是 B 的颜色固定、不从封面来，版面是左右两栏而不是舞台加纸。
