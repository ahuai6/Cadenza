# Cadenza 設計語言：舞台

第二版（3.1 起）。取代先前的「Liner Notes」。這份文件是介面的規則書：先講想法，再講數值，最後講怎麼用這些積木拼出新畫面。數值都在 `src/app/styles/tokens.css`，元件在 `src/app/ui/`；文件與程式不一致時，先改文件再改程式。

## 1. 想法

Cadenza 和別的播放器只差一件事：歌詞是會動的畫面。所以介面的結構也照這件事排：

**正在播放的歌就是舞台，其他東西都是暫時走上舞台的道具。**

- **首頁是「正在播放」**，不是音樂庫。打開程式看到的是這首歌：封面、歌名、歌詞，整個視窗染上封面的顏色。
- **音樂庫是一張紙**，從下方升起蓋在舞台上；舞台退後、變暗，但還在。放下這張紙就回到歌。
- **播放控制是舞台的台口**：永遠在最下面一條，兩種狀態下都是同一條，不會換位置。
- **專輯站在一條線上**：這條線同時是進度與節拍的線（見第 6 節）。

由此得到四條判斷標準，設計任何新畫面時依序問：

1. **它屬於這首歌，還是屬於音樂庫？** 屬於歌的放在舞台上，屬於庫的放在紙上。不新增第三種地方。
2. **它的顏色從哪來？** 從封面來。介面自己不帶彩色；需要強調時用這首歌的顏色。
3. **它在動的話，跟著什麼動？** 跟著手（使用者的操作）或跟著音樂（拍點、歌詞時間）。沒有第三種理由的動畫不做。
4. **一般人需要看到它嗎？** 不需要的收進「進階」。技術名詞不上主畫面（見 `docs/COPY.md`）。

## 2. 顏色

**一首歌一個色相。** 播放中的歌的封面決定色相（引擎的調色盤 `session.ambient`），外殼把它寫成 `--song-h`（色相）與 `--song-c`（彩度係數）。沒有歌時是暖灰（色相 30、彩度 0.25）。

| 角色 | token | 深色 | 淺色 |
|---|---|---|---|
| 舞台底 | 引擎畫的環境色場 | 封面色的流動色場 | 同左（舞台永遠是深的） |
| 紙（音樂庫的底） | `--bg` | 這首歌色相的極深色（明度約 12%） | 這首歌色相的極淺色（明度約 95%） |
| 文字 | `--fg` / `--fg-2` / `--fg-3` | 象牙白與兩級灰 | 墨與兩級灰 |
| 選中、主要動作 | `--pick` / `--on-pick` | 象牙白底、墨字 | 墨底、象牙白字 |
| 這首歌的顏色（正在播放的標記、進度、連結） | `--accent` | 色相的亮調（明度約 76%） | 色相的深調（明度約 36%） |
| 危險 | `--danger` | | |

規則：

- **選中用反白，不用彩色。** 分頁、分段控制、主要按鈕選中時是「紙的反色」；彩色只留給「這是正在播放的歌」。
- 換歌時顏色在 1.2 秒內過渡，不跳。
- 文字對底色的對比至少 4.5:1；`--fg-3` 只用在 24px 以上的字或非必要資訊。
- 舞台上的東西用 `.on-picture`（白字、深色毛玻璃）；紙上的東西用一般 token。同一個元件兩邊都能放。

## 3. 字

- 一個字族：介面字體（預設 Instrument Sans＋思源黑體），標題只是更重、更大，不換字體。設定裡可換（`uifont.ts`）。
- 字級只有七級：

| token | 大小／行高 | 字重 | 用在 |
|---|---|---|---|
| `--type-hero` | 44/1.05 | 700 | 紙的大標題（「音樂庫」） |
| `--type-title` | 34/1.15 | 700 | 舞台上的歌名 |
| `--type-lyric` | 38/1.3 | 700 | 舞台上的歌詞（依視窗縮放） |
| `--type-head` | 22/1.25 | 650 | 區塊標題、卡片標題 |
| `--type-body` | 16/1.45 | 450（強調 600） | 列表標題、內文、按鈕 |
| `--type-note` | 14/1.4 | 450 | 副標、說明 |
| `--type-tiny` | 12/1.3 | 550 | 數字、時間、標籤 |

- 數字用等寬數字（`tabular-nums`）。不用全大寫加寬字距的小標籤（上一版的 kicker 取消）。
- 一行放不下的歌名不截斷成「…」，用跑馬燈（`ui/Marquee`）。

## 4. 形狀與間距

**圓角四級＋膠囊**，依「東西有多大、浮不浮」決定：

| token | 值 | 用在 |
|---|---|---|
| `--r-1` | 10px | 列表裡的封面、標籤、小塊內容 |
| `--r-2` | 14px | 輸入框、選單項目、列表的一列、網格封面 |
| `--r-3` | 20px | 浮起來的：選單、彈窗、面板、舞台上的大封面 |
| `--r-4` | 28px | 紙（只有上面兩個角） |
| `--r-pill` | 999px | 所有按鈕、分頁、分段控制、開關 |

巢狀時內層取「外層減間距」。**封面永遠完整顯示、不裁切**：容器跟著封面的比例走，不是把封面塞進固定的方格。

**間距**用 4 的倍數：4、8、12、16、24、32、48、64、96。頁面左右留白：紙 56px，舞台 104px（視窗窄於 1100px 時各減半）。

**可點的東西至少 44×44px。** 圖示按鈕是 44px 的圓；圖示本身 20px、線寬 1.8。

**表面**只有三種：

1. 舞台：沒有邊、沒有底，直接在色場上。
2. 紙：實色、上緣圓角 28px、往上投一道柔和的長陰影。
3. 浮層（選單、彈窗、佇列、設定抽屜）：圓角 20px、毛玻璃或實色、一道陰影。

列表不畫格線、不用卡片；一列在滑過時才出現圓角底色。

## 5. 動態

**一條曲線**：`--ease`＝`cubic-bezier(0.16, 1, 0.3, 1)`，先快後慢。可以被打斷的大動作（紙的升降）用彈簧（`motion.ts` 的 `Drive`），中途反向不會跳。

| token | 時長 | 用在 |
|---|---|---|
| `--t-fast` | 120ms | 滑過、按下的回饋；任何東西離場 |
| `--t-med` | 220ms | 選中狀態改變（分頁、開關、圖示按鈕） |
| `--t-enter` | 320ms | 一塊內容進場（淡入＋上移 8px） |
| `--t-stage` | 620ms | 紙升降、舞台退後、抽屜滑入 |
| `--t-song` | 1200ms | 換歌時的顏色過渡 |

規則：

- **離場比進場短**，新舊兩層不疊在一起。
- **紙升起時舞台同時退後**：縮到 0.9、上移 36px、變暗到 18%。這是同一個動作，共用一個進度值，不分兩段。
- **列表進場**每列延遲 16ms，最多 12 列，之後一起出現。
- **歌詞等待時是三個點**（前奏或四秒以上的間奏）：隨等待的進度由左到右亮起，跟著歌曲時間，不是循環動畫；這時下一句歌詞已經淡淡地在它的位置上，開口時只是變亮，不是跳出來。
- **跟著音樂的動態**（節拍線上的脈動、封面的呼吸）只在播放時動，幅度小於 4%，並遵守「減少動態」設定。
- 「減少動態」開啟時：所有位移改成淡入淡出，彈簧直接到位。

## 6. 節拍線（專輯）

專輯不是網格，是站在一條橫線上的一列封面。

- 線在紙的中段偏下，橫貫整張紙；線下方有細刻度。
- 封面底邊貼著線，一張接一張；選中的那張在正中央、放大 1.5 倍，其餘半透明。點任何一張，整列滑動讓它到中央。
- 線的上方是選中專輯的名字與演出者；線的下方是它的曲目。
- 播放的專輯正是選中的這張時，線從左邊開始被這首歌的顏色填滿到目前進度，進度點上有一圈跟著拍點擴散的環。
- 滾輪與左右鍵移動選擇；兩側淡出。點選中的那張（或按 Enter）就播放。
- 專輯依開頭字母排（英文字母、中文的拼音首字母、假名的羅馬字首字母，其餘在 #），十二張以上且不只一個字母時，線上方有一排字母，點了跳到那個字母的第一張。

## 7. 積木

新畫面用這些拼，不另外發明。全部在 `src/app/ui/kit.tsx`（除非另註）。

| 積木 | 是什麼 | 規則 |
|---|---|---|
| `Pills` | 一排膠囊分頁／分段控制 | 選中是反白；最多 6 個，更多改用選單 |
| `Button` | 膠囊按鈕 | `kind`：`solid`（反白，一個畫面最多一顆）、`ghost`（細邊）、`danger` |
| `IconButton` | 44px 圓形圖示鈕 | 一定有 `label`（提示與無障礙名稱） |
| `Row` | 列表的一列：封面、兩行字、尾端資訊 | 封面 56px；整列可點；右鍵是指令選單 |
| `Cover` | 封面 | 不裁切；沒有封面時是這首歌色相的色塊加音符 |
| `Sheet` | 紙 | 整個程式只有一張 |
| `Drawer` | 從右側滑入的抽屜（歌曲設定） | 寬 420px；背後是可點擊關閉的暗幕 |
| `Toggle` / `Slider` / `Select` | 設定用的控制項 | 由設定綱要產生（`settings/schema.ts`），不手寫 |
| `Disclosure` | 「進階」摺疊 | 預設收起；裡面才可以出現技術名詞 |
| `Marquee` | 太長的字 | 取代「…」 |

**一個動作只有一個入口定義**：按鈕與選單的名稱、圖示、行為都來自指令登記表（`src/app/commands/`）。

**新增一個畫面的步驟**：

1. 用第 1 節的四個問題決定它放在舞台還是紙上。
2. 用上表的積木排出來；缺積木時先在這份文件加一列，再寫進 `ui/`。
3. 顏色、圓角、時長只用 token（`tests/unit/arch.test.ts` 會擋字面值）。
4. 文字先過 `docs/COPY.md`。
5. 在 `tests/desktop.cjs` 加一段檢查。

## 8. 版面

| 位置 | 規則 |
|---|---|
| 頂列 | 高 56px，浮在一切之上：左邊品牌名，正中央導覽膠囊（正在播放／音樂庫／海報牆／歌詞工坊），右邊設定與視窗按鈕 |
| 台口（播放列） | 高 96px，最上緣一條 3px 進度線橫貫視窗；左邊小封面與歌名（只在紙升起時出現），正中央播放控制，右邊佇列、音量、收藏 |
| 舞台 | 頂列與台口之間。左邊封面（中心在視窗 ¼ 線上）與歌名，右邊歌詞從 ½ 線開始 |
| 紙 | 上緣在頂列下方 16px，下緣貼著台口。標題列：大標題在左，分頁膠囊在右；內容可捲動 |
| 設定 | 紙上的一頁：常用的在上面，節奏、畫面、資料在最下面的「進階」裡（開過會記得）。待做：由設定綱要產生 |

## 特效歌詞與歌曲設定面板（沿用）

- 特效與動畫完全不改。
- 畫面四周的黑邊與模糊轉場的遮罩，改用封面色調的深色，和播放頁一致，不再是固定的近黑色。
- 控制列和側邊面板使用與播放頁相同的深色毛玻璃與圓角。
- **歌曲設定面板（2.19）**：
  - 一整片毛玻璃，以這首歌的深色調染色。
  - 左側是分頁直欄（封面縮圖在最上，匯出放最下），右側是打開的分頁：標題用展示字體，各部分依序編號 01、02……
  - 風格用卡片呈現，每張卡片畫出它的鏡頭路徑；推薦的那張有標記，選中的以強調色描邊。
  - 微調滑桿在 1.00× 處有刻度，調離 1.00× 時軌道與數值改用強調色。

## 字體檔

- 字體登記在 `src/text/fonts.ts`（歌詞）與 `src/app/uifont.ts`（介面），按風格分為細、粗、襯線、手寫、藝術幾類。
- 所有字體都是 SIL OFL 1.1，允許隨程式發佈，因此全部打包在 app 內，不必線上下載。
- 選用之前會先載入要顯示的字（`ensureFont` 會預先載入歌詞用到的字），換字體時不會先閃一下別的字體。
