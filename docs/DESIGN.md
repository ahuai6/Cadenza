# Cadenza 设计语言「书页」

方向 B 是经典和空间的现行视觉规范。经典画面把曲库做成目录，右侧常驻「正在播放」。空间保留可走动的展馆和马赛克画面，导航、控制和信息用同一套书页设计。原型和其假数据在 [方向 B 原型](design/direction-b-book.dc.html)。

## 颜色与字体

| 角色 | 说明 |
| --- | --- |
| 纸面 | 暖白 `#F3F1EC` 或纯白 `#FFFFFF`，页面、播放右栏与普通浮层同底色。分区优先使用留白或大块低对比底色 |
| 墨色 | `#1D1B18` 为主要文字及深色跨页，`#5F5A52` 为浅色次要文字 |
| 强调 | 浅色 `#A03D18`，深色使用更亮的陶土色，用于正在播放、链接及焦点 |
| 深色 | 采用暖灰褐色纸面和暖白字，依据设置和系统外观选择 |
| 内容 | 封面、画布、用户选的背景与特效保留自身色彩 |

章标题、品牌和歌词跨页采用衬线字，默认拉丁字使用 Source Serif 4 或其本地备用，中文、日文、韩文使用各自的 Noto Serif。正文采用无衬线字，用户的界面字体和歌词字体设置继续有效。桌面打包附带字体。时间使用等宽数字。

## 布局与组件

- 宽窗口由固定页眉、独立滚动的章节及右侧播放栏组成。歌曲按目录列展示，专辑是自适应封面网格，歌单按名称和首数排列。详情和设置用细线、标题及连续留白组织。海报墙保留浏览方式与封面构图，工坊的画布和编辑工具遵循同一层级。
- 应用启动时选中音乐库的「歌曲」。右侧恢复上次曲目和队列，跟随纸色或纯白主题，并在宽窗口里以紧凑版逐字歌词显示当前及邻近歌词。展开歌词后，窗口左侧是封面及歌曲动作，右侧是可定位的歌词。底部集中播放、进度及输出控制。窄窗口下播放栏变为紧凑底栏，跨页可将歌曲信息排在歌词上方。
- 专辑色晕在窗口坐标中绘制并延伸至顶栏，向右和向下逐步淡至透明。常规播放页的底座与图像在顶栏下沿展开，顶栏在自身区域整栏淡变至播放页底色，导航和位置保持稳定。
- 空间顶部是展馆章节、搜索及窗口操作，播放在底部。导览、播放、搜索结果、详情、设置、歌词、队列、菜单与下拉选项使用带实时马赛克的 46% 填色。空间渲染逐帧同步背景和面板的位移与透明度。进入新区域时只显示地点名称及细标记。
- 普通触控目标至少 44 CSS 像素。提供清楚的键盘焦点、禁用、选中、按下、加载和空状态。曲目菜单可点开，悬停和右键作为桌面快捷操作。窄屏保留可滚动导航和可用动作，窗口拖动区独立于页面控件。
- 样式尺寸与调色板集中在 `src/app/styles/tokens.css`，通用按钮、分段选择、下拉、菜单、浮层和开关使用 `src/app/ui`。窗口装饰仍通过桌面桥接，页面组件不直接依赖平台。

## 动效与层级

| 动作 | 时间与行为 |
| --- | --- |
| 按下和悬停 | 120 毫秒，悬停轻微放大并提亮，按下收紧并略暗。减少动态效果时保留明暗反馈 |
| 菜单与二级菜单 | 220 毫秒进入、120 毫秒退出，跟随触发点，自动避让窗口边缘 |
| 页面和标签切换 | 旧内容先淡出约 120 毫秒，新内容接着淡入约 180 毫秒。旧内容退出时停止接收焦点和指针，连续点击以最后选中的目的地为准 |
| 弹窗及抽屉 | 420 毫秒进入、120 毫秒退出，和遮罩一起出现 |
| 展开歌词 | 一条可反向的弹簧进度推动侧栏底座向左伸展。宽窗口内封面在同一水平线上往返，资料、选定背景、歌词和控制随进度出现。紧凑底栏与纵向堆叠布局共用进度，以淡入淡出交接封面 |
| 减少动态 | 跳过位移、大幅缩放和强模糊，状态直接到达；状态反馈和播放进度保持可读 |

默认缓动为 `cubic-bezier(.2,.8,.2,1)`。层级依次为纸面、扩展底座和图像、歌词、播放器、界面导航、菜单和对话框。排版只在开合起点或尺寸变化时量测，动画帧只更新可视范围及变换。Windows 热键和窗口操作与页面交互分离，响应式、指针和键盘规则为未来触控平台共用。
