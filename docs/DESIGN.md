# Cadenza 介面設計：Liner Notes

一套視覺語言，三種情境。名字取自唱片內頁的「內頁說明」：靠排版與細線分出層次，而不是靠卡片、底色或陰影。

## 共同語言（`src/app/styles/tokens.css`）

**字體**
- 介面用 Instrument Sans。中日韓文字依介面語言改用對應的 Noto Sans。
- 標題用 Fraunces（可變字重與光學尺寸），中日韓文字改用 Noto Serif。
- 小標籤一律是全大寫加寬字距的小字（`--kicker`）。數字使用等寬數字。
- 設定裡可以改介面字體，詳見 `uifont.ts`。

**圓角**：只有四級，依「東西浮不浮」決定。
| token | 值 | 用在 |
|---|---|---|
| `--r-1` | 2px | 內容：封面、列表裡的縮圖、標籤 |
| `--r-2` | 6px | 控制項：按鈕、輸入框、分段控制、選單項目 |
| `--r-3` | 12px | 浮在上面的：選單、下拉、彈窗、佇列、側邊面板、提示 |
| `--r-pill` | 999px | 只用在播放鍵和開關 |

巢狀的形狀取「外層減間距」，輪廓保持同心。

**表面**
- 頁面是平的：一層底色，用髮絲線（`--line`）分隔，不用卡片，也不用陰影。
- 浮起來的東西才有表面（`--float`），加一條細邊和一層柔和陰影。
- 在畫面上（播放頁、特效歌詞）改用深色毛玻璃（`.on-picture`）。

**顏色**
- 深色是「墨」：#0e0e0d 帶一點暖；淺色預設是「紙」：#f4f2ec，也可選以前版本的「白」（`data-tone="white"`：底 #f6f5f9、表面純白，強調色不變）。
- 只有一個強調色（朱紅：深色 #ff6a3d、淺色 #d4461f），用在目前播放、選中狀態和主要動作。
- 品質標章各自有顏色，但都降到低飽和。

**動態**
- 只有一條主曲線 `--ease`：`cubic-bezier(0.16, 1, 0.3, 1)`，先快後慢。
- 離場一律比進場短，避免新舊兩層疊在一起：
  - 選單、彈窗：進場 220ms 從觸發點的方向放大淡入，離場 120ms 淡出；
  - 換頁：舊頁 120ms 淡出，新頁 320ms 上移 8px 淡入；
  - 側邊欄的選中標記在項目之間滑動。
- 迷你播放列展開成播放頁維持一條彈簧（`layers.ts`），中途可以反向。

## 版面網格（2.20.1 起）

每個頁面都可以用矩形切開來看。主要對齊線是視窗的 ½ 與 ¼；需要靠「視覺平衡」決定的位置，也一律落在某條分割線上，或用容器的幾分之幾表示，不用零散的像素值。

| 位置 | 規則 |
|---|---|
| 側欄寬度 | 視窗的 ⅙（220–280px 之間） |
| 播放頁封面 | 中心在視窗 ¼ 線上（`--np-cx`） |
| 播放頁歌詞 | 文字從 ½ 線開始；右緣離視窗右邊的距離 = 封面左緣離視窗左邊的距離（`--np-x`），左右對稱 |
| 播放頁頂列 | 切換鈕在 ½ 線；收起鈕的圖示對齊封面左緣，選單鈕對齊歌詞右緣 |
| 播放頁左欄 | 歌名、進度、控制、音量與封面同寬 |
| 底部播放列 | 左右兩側等寬，播放控制正好在 ½ 線；小封面中心在 ¼ 線（展開時封面沿這條線垂直上升）；封面左邊的空間放音量，置中 |
| 專輯等詳細頁 | 封面欄佔內容寬的 ¼，文字欄 ¾ |
| 設定 | 目錄佔 ¼，內容佔 ¾ |
| 歌曲設定面板／工坊面板 | 分頁直欄固定寬，內容欄其餘 |
| 海報牆 | 滿版，海報之間 2px 細線 |

## 一、音樂庫：Editorial Minimalism

- **頁首**：小標籤加上大號襯線標題，下面一條細線，右側放數量與排序。
- **歌曲列表**：一張表格。
  - 表頭是小標籤（#、標題、專輯、品質、時長），列之間用髮絲線分隔；
  - 縮圖 40px、圓角 2px；目前播放的那一列以朱紅色的編號或均衡器標示，不加底色；
  - 滑過一列時只微微加深底色，操作按鈕才出現。
- **專輯、歌手、類型、歌單**：方形封面網格，封面幾乎直角。
  - 標題用介面字體的粗體，副標用灰色；
  - 滑過時封面浮起 2px，並出現圓形播放鍵。
- **詳情頁**：像唱片內頁。
  - 左邊是大封面，右邊是小標籤、大號襯線標題和資訊列（年份 · 曲數 · 總長）；
  - 下方曲目表以曲序編號開頭。
- **側邊欄**：
  - 最上方是襯線字的品牌名；
  - 導覽項目只用文字和細圖示，選中時左側一條 2px 朱紅標記，並會滑動；
  - 底部是分析進度、輸出切換與設定。
- **設定**：兩欄式。左欄是分組標題與說明，右欄是控制項；組與組之間用細線分隔。

## 二、播放頁：Cinematic Ambient

- **背景**：以引擎的環境色場（封面顏色）為底，再疊三層：
  - 封面後方的大範圍柔光（bloom）；
  - 邊緣的暗角（vignette）；
  - 極淡的顆粒（grain），讓大面積色塊不平板。
- **封面**：大尺寸，圓角 6px，帶一層由封面顏色而來的長陰影。
- **文字**：歌名用襯線字，歌手與專輯用細一點的無襯線字。控制項全部是白色加透明度，一樣的大小，沒有底框。
- **歌詞**：動效完全不變（類 Apple Music）。字體可以在設定中另外選擇。
- **第三輪（2.19）**：
  - 頂部中央是一顆毛玻璃切換鈕「歌詞／特效歌詞／佇列」，取代原本右上角的「特效歌詞」按鈕；佇列從這裡打開。
  - 歌名上方一行小型大寫字：專輯 · 年份 · 第幾首；歌名用展示字體放大，歌手在下。收藏是一顆圓形按鈕，放在歌名右側。
  - 音量獨立一行、平時半透明，滑到上面才完全顯示。
  - 歌詞字級約 24–38px，整欄往右移，左右兩欄的重量更平衡。
  - 播放頁覆蓋整個視窗（2.19.1），只留視窗按鈕在上方。

## 三、特效歌詞

- 特效與動畫完全不改。
- 畫面四周的黑邊與模糊轉場的遮罩，改用封面色調的深色，和播放頁一致，不再是固定的近黑色。
- 控制列和側邊面板使用與播放頁相同的深色毛玻璃與圓角。
- **歌曲設定面板（2.19）**：
  - 一整片毛玻璃，以這首歌的深色調染色。
  - 左側是分頁直欄（封面縮圖在最上，匯出放最下），右側是打開的分頁：標題用展示字體，各部分依序編號 01、02……
  - 風格用卡片呈現，每張卡片畫出它的鏡頭路徑；推薦的那張有標記，選中的以強調色描邊。
  - 微調滑桿在 1.00× 處有刻度，調離 1.00× 時軌道與數值改用強調色。

## 字體

- 字體登記在 `src/text/fonts.ts`（歌詞）與 `src/app/uifont.ts`（介面），按風格分為細、粗、襯線、手寫、藝術幾類。
- 所有字體都是 SIL OFL 1.1，允許隨程式發佈，因此全部打包在 app 內，不必線上下載。
- 選用之前會先載入要顯示的字（`ensureFont` 會預先載入歌詞用到的字），換字體時不會先閃一下別的字體。
