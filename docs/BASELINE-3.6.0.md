# Cadenza 3.6.0 基线与 G0 记录

基准提交为 `4157fd8ceb7404811c57c29ea3f7f4d133f5af4b`。G0 交付可重跑的隔离测试、测量记录和架构规则。应用本身仍是 3.6.0，播放、渲染及数据生命周期行为未在 G0 改动。后续 G1–G9 应各自获得授权。

## 在 Windows 上复跑

使用仓库锁定版本的 Node 依赖。Playwright 放在独立工具目录，本次使用 1.65.1。桌面回归另外需要 FFmpeg、Git Bash、Python 和与解释器版本匹配的 NumPy、Pillow。Hi-Fi 套件使用本地基准音频核心，优先传入基准源码的构建产物。Folia 使用 `src/folia/upstream.json` 固定的上游版本。参考工具目录需要上游锁文件指定的 Pixi、React、React DOM、Framer Motion、Lucide、Pretext、Vite 和背景依赖，包括 `twgl.js`、`zustand`、`@paper-design/shaders-react`。

```powershell
$env:CADENZA_BASELINE_TOOLS = '<隔离工具目录>/node_modules'
$env:CADENZA_BASELINE_NATIVE = '<基准构建>/cadenza-audio.exe'
$env:CADENZA_BASELINE_PYTHON = '<Python 路径>/python.exe'
$env:CADENZA_BASELINE_SH = 'C:/Program Files/Git/usr/bin/bash.exe'
$env:PATH = 'C:/Program Files/Git/usr/bin;' + $env:PATH
$env:CADENZA_BASELINE_FOLIA = '<带参考依赖的独立 Folia 检出目录>'

node tests/baseline/run.cjs playback gpu
node tests/baseline/run.cjs render space
node tests/baseline/run.cjs desktop native desktop-hifi
node tests/baseline/run.cjs folia
```

每次从 Git 提取固定提交到一个新的 `cadenza-baseline-*` 临时目录。构建、合成曲库、Electron profile、Chromium 存储、导出、截图、日志和比较都在该目录。工具、依赖与模型由机器提供，运行器记录版本或 SHA-256。隔离版主进程启动前验证 profile 的实际路径，并禁用测试中的开机启动设置和全局媒体键注册。基准运行器拒绝 `--reset-data`。Folia 的测试套件使用可移植的本地测试入口，参考绘图与 Cadenza 产品源码固定在各自的基准提交。

`report.json` 记录各套件及其日志。运行器保留原始结果供复查。退出码 0 表示所选测试通过，1 表示有失败，2 表示有未满足的测试前置条件。测时套件应独立运行。桌面模型可从当前仓库外部资产目录复制，且须通过基准清单的 SHA-256 校验。

## G0 验证结果

环境为 Windows 11 build 26300、Core i9-12900H、Node 24.22.1、Electron 45.1.0、Playwright 1.65.1。Hi-Fi 使用本地预编译 Rust 音频核心，其 SHA-256 为 `6682b2fb7ee29dce1c1de102a9c5740a4cfc98173afd947d7887e474984e207c`。本轮未从 Rust 源码复建该产物，硬件输出能力另行验收。

### 播放时间

从自动化调用正常的 `playIds` 入口计时。暖切换往返于已经准备过的两首 12 秒 WAV，缓存冷切换使用不同的目标条目。每路各取 30 个暖样本、30 个缓存冷样本和 1 个首播样本。普通输出的信号由 Web Audio 图中的 FFT 读出，信号随后静音。Hi-Fi 的信号由模拟设备写入的立体声 PCM 中分辨，另记首个可运行的位置事件。两者都只代表各自的观察点。视觉用现有起播 trace 记录初始规划，另记完整分析计划就绪。

表中单位为毫秒，数字为 **P50 / P95**。

| 路径、场景 | 旧信号结束 | 新信号出现 | 初始视觉规划 | 完整分析计划 |
| --- | ---: | ---: | ---: | ---: |
| 普通、暖切换 | 47.4 / 67.5 | 82.0 / 126.9 | 48.3 / 72.9 | 46.7 / 67.5 |
| 普通、缓存冷切换 | 150.6 / 173.0 | 188.2 / 212.1 | 149.1 / 170.1 | 152.0 / 173.4 |
| 模拟 Hi-Fi、暖切换 | 27 / 75 | 43 / 75 | 44.0 / 75.4 | 42.4 / 70.8 |
| 模拟 Hi-Fi、缓存冷切换 | 17 / 170 | 139 / 170 | 139.2 / 159.7 | 143.2 / 162.8 |

上表各 30 个样本均取得对应时间点。单次首播，普通路径的新信号是 325.6 ms，初始视觉规划是 316.1 ms；模拟 Hi-Fi 分别为 537 ms、326.2 ms。模拟 Hi-Fi 的首个运行位置事件比设备写入晚，缓存冷切换 P95 为 219.4 ms。初始规划和完整分析计划的探针各自取样，P50、P95 可能交叉。普通与 Hi-Fi 两路的信号探针位于不同位置。后续阶段比较应沿用同路口径。真实采集还需要独立的 WASAPI 共享环回与独占硬件环回，并覆盖播放时钟误差。

### 渲染、界面和回归

硬件探针在 Chromium ANGLE 的 RTX 3070 Ti Laptop GPU D3D11 路径上运行，分辨率 1920×1080，DPR 为 1，每个主题预热 30 帧后记录 120 帧。CPU 提交时间与浏览器帧间隔独立记录，显卡执行时间、显存及上下文恢复由后续阶段测量。浏览器在本机实际以约 7 ms 的周期调度，结果保留此环境事实。

| 主题 | 同步绘制提交 P50 / P95 / P99（ms） | 浏览器帧间隔 P50 / P95 / P99（ms） |
| --- | ---: | ---: |
| liquid | 1.8 / 2.9 / 20.3 | 7.0 / 7.8 / 48.7 |
| gothic | 1.3 / 2.5 / 19.1 | 7.0 / 13.9 / 90.6 |
| cover | 1.9 / 3.1 / 21.1 | 7.0 / 7.3 / 20.9 |

软件渲染回归通过 27 项，空间回归通过 28 项，经典桌面回归通过 76 项。查看了经典播放页和空间队列截图。模拟设备的原生与桌面回归均通过，覆盖样本、暂停、跳转、释放、采样率切换和关闭 Hi-Fi。单元测试通过 38 套、378 项，包含 8 项架构与样式检查。编译类型检查通过。

Folia 对照以 `6ee9404` 为参考。静态场景商籁、凝彩各取 68 帧，粗粒度前景 IoU 均为 93.8%，平均色差分别为 0.62% 和 2.90%。开启拍点效果后各取 17 帧，粗粒度前景 IoU 分别为 96.1% 和 98.8%，平均色差分别为 0.53% 和 2.22%。舞台 13 项均生成比较结果。静态背景平均色差为 0.00%–0.14%，通用背景的动态几何为 0.02%，莫奈动态为 0.25%。已有的差异记为基准，G7 应结合完整帧和相同环境的对照决定是否达标。

## G0 发现与验证缺口

- AST 检查发现四组已有运行时依赖环，共 10 条边。G0 冻结这些边，解环留给相关阶段。旧规则挡不住裸导入、双引号和别名。新规则加入正反例以及渲染端平台包的检查。
- 旧 Folia 参考构建硬编码 Linux 路径，并遗漏同一 Vite 配置使用的背景入口。G0 仅更新测试入口，保留原始绘图和上游同步能力。
- 首次隔离桌面回归发现缺模型产生的控制台 404。复跑加入按基准 SHA-256 校验的本地模型，测试环境与发布资源更接近。用户数据未参与上述复跑。
- Windows 工作树中原有文件是 CRLF，默认全库格式检查按配置要求 LF。已修改的测试文件通过配置检查，全库按 `npm.cmd run format:check -- --end-of-line auto` 检查通过，避免无关的换行改动。
- 实际声卡的停声与出声、逐字歌词与设备时钟误差、真实 DAC 的样本和硬件释放、长时 GPU 显存及安装或便携版的升级清理留待对应阶段。G0 未执行真实数据清理。
