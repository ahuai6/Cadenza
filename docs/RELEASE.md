## Cadenza 1.5.0

**依賴全面升到最新穩定大版本**

本版沒有新增功能，只把底層依賴升到最新穩定版。以後的開發也都以各依賴的最新穩定版為準（規則寫在 README 的「依賴」一節）。

- **Electron 45**：桌面端內建的 Chromium 和 Node 都換成新版，渲染、匯出和 WebGPU 神經網路引擎都跟著更新。
- **TypeScript 7**：改用新版編譯器做型別檢查，並移除新版已不支援的舊設定。
- **影片匯出換用 Mediabunny**：原本用來封裝 MP4 的 `mp4-muxer` 已停止維護，作者指定 Mediabunny 接替，所以換了過去。匯出的檔案格式不變。
- **影片背景與 MV 讀取（mp4box 2）**：匯出時逐幀解碼影片背景和 MV 的部分，已改用 mp4box 2 的新介面。
- **Hi-Fi 播放核心**：解碼器升到 symphonia 0.6，重採樣器升到 rubato 5。播放仍然位元完美，必要的取樣率轉換和跳轉照常運作。
- **發佈流程**：CI 改用 Node 26（目前的長期支援版），GitHub Actions 也升到最新版。

**修正**
- 從特效歌詞返回正在播放時，標題列的品牌與搜尋框偶爾會在畫面還很模糊時就先浮現。現在它們會等模糊開始散去才淡入。
