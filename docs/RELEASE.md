## Cadenza 2.9.3

**修正：特效歌詞調參時很卡，以及幾個不生效的設定**（審計報告 `docs/AUDIT.md` 第 1 步）

**修正**
- **拖動旋鈕不再卡住**：以前每拖動一下就把整個鏡頭和排版重新規劃一次，每次 0.3～1.3 秒，拖一下就卡好幾秒。現在拖動時只更新畫面，放開滑鼠後才重新規劃一次。
- **歌詞微調、片尾長度滑桿**：
  - 以前每動一下就從頭重建整首（重新解析歌詞、分詞、等字體），而且等字體的期間會同時堆起幾十個重建。
  - 現在放開後才重算，而且只重算時間，不再重新解析和分詞；任何時候都只會有一個重建在跑。
- **「色散」「故障」開關**：以前打開後不會出現，要改了別的設定才生效。現在切換後立即生效。
- **「漂浮感」旋鈕**：以前只改字的漂浮，鏡頭的漂浮和擺動不變。現在兩者都會跟著變。
- **「進場時長」旋鈕**：以前字提前出現的時間不跟著變。現在會跟著變。
- **只重算需要的部分**：碎玻璃、字形紋樣、色散、故障的開關，以及「重拍觸發靈敏度」「字形紋樣頻率」，現在只重算特效觸發，不再整個重新規劃。
