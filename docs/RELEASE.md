## Cadenza 2.4.0

**新歌詞類型「圓心」、新特效「字環」、手動歌詞框「$1」，「流動」更常往上下排**

**歌詞類型**（特效歌詞面板 › 動態 › 歌詞類型）
- **流動**：一行接一行時，排在上一行上方或下方的機率提高，一直往右走的情況少了，不再顯得著急。
- **圓心（新）**：
  - 第一句放在場景中心附近，之後每一句以前一句為圓心，環繞放在它的上下左右；
  - 縱深更大，各句前後拉得更開，更立體；
  - 放置時偶爾會轉向，但只會轉到讓字的上方朝向圓心外側，不會朝向圓心，也不會倒過來；
  - 沒有轉向的句子保持正立。

**特效**
- **字環（新）**：歌詞出現時，有機率在字的底下浮現一圈大小不一的環。
  - 「數量」調整出現的機率。
  - 「樣式」可選：
    - 顫動波紋：一到三圈往外擴散、邊緣顫動的波紋，顫動會隨拍子加強；
    - 規整光環：正圓的發光環，外圈有反向旋轉的弧線與刻度，在深色畫面上發光，採用主題的強調色。

**歌詞編輯**
- **手動歌詞框**：
  - 在一個詞前面寫 `$1`，這個詞就會被框起來；
  - 不論是否開啟「歌詞框線」都會出現，特寫鏡頭也一樣；
  - 逐字歌詞和一般歌詞都支援，符號本身不會顯示；
  - 自動挑選的歌詞框會避開這幾行附近。
- **快捷欄**：歌詞編輯框上方的符號列加入 `$1`（歌詞框），快捷鍵是 Alt+4。
