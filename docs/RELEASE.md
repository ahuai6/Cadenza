## Cadenza 2.7.0

**往左的歌詞改為懸停取景、歌詞不再一直往一個方向走、同畫面最多三行、歌詞依遠近各自受力**

**改動**
- **往左的歌詞**：
  - 鏡頭改用「懸停」風格：每組詞一個停點，停在詞組中間上方，不逐字跟隨，並朝畫面左方（歌詞的走向）微微領先、緩慢漂移，看得出在往左走。
  - 往左的段落裡，每一行都明顯往左一步（新行的中心在前一行開頭的左側）。
  - 以前只有短到能整行取景的行才往左排，現在任何長度都可以。
- **不再一直朝一個方向走太遠**（「疾走」場景除外）：
  - 一段走到離起點一定距離後，接下來的歌詞改放在前一行的上方或下方，並且和再前一行錯開，所以三行會上下交錯；位置也會稍微退回起點方向。
  - 撞到時只往上、往下或往起點方向推開，不再往前推。
  - 再走遠就換到下一段（模糊轉場）。完全沒有空檔時才在原頁繼續；這時只要有真的重疊、又有 0.2 秒空檔，仍然做快速模糊轉場。
  - 圓心模式所有角度都放不下時，改為模糊轉場、開一個新的圓，不再擠在圓心附近。
- **同畫面最多三行**：當前一行和前兩行。第四行出現時，最舊的一行立即淡出；鏡頭看不到時直接移除。排版只需避開還在畫面上的這幾行。
- **依遠近各自受力**：畫面的晃動、搖擺、震動與傾斜，依每個字的遠近作用：近的受力較多（最多 1.3 倍），遠的較少（最少約三分之一）。推近只對遠處減弱。每個字的節拍抖動也一樣依遠近縮放。歌詞因此不再像同一個平面圖層一起動。
