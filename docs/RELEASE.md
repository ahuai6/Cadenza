## Cadenza 1.0.2

### 介面
- 主題頁：使用預設主題且沒有修改時，不再顯示「未保存的自定義主題」；只有真的改過設定才會出現。
- 海報牆「長廊」模式可以直接點擊海報與「播放」按鈕播放（之前拖動判定攔截了點擊）。
- 播放頁歌詞滾動後，游標指向與點擊的位置和畫面一致（整行一起移動，點擊區域跟著走）。
- 迷你播放器展開/收起重新設計：畫面一開始就先往左側（封面飛去的方向）展開，再向上、向右；靠近卡片時與卡片底色互相淡入淡出，收回時不再從封面色跳變成底色。

### 效果歌詞
- 文字的立體邊緣與陰影從入場第一幀就隨對焦一起出現，不再入場結束後才突然冒出。
- 轉場的分寸重新拿捏：需要移動略超過一個畫面才能放下歌詞時會轉場，其餘情況仍讓鏡頭移動；轉場依舊不會遮住還沒唱完的字。
- 鎖鏈特效只跟隨每小節的重拍，不再隨每個小拍顫動。
- 轉場模糊更輕、更通透，不再像蓋上一層厚幕。
- 刪除片尾拉高拉遠的鏡頭，結尾鏡頭停留在最後的歌詞上輕輕漂移。

### 播放頁 ⇄ 特效歌詞
- 過渡更俐落（彈簧約 0.9 秒落定，封面先行）。
- 封面陰影全程連續過渡：從播放頁的陰影逐漸變成特效畫面裡的陰影；封面的光澤與邊光隨畫面一起漸入，沒有任何跳變。
- 播放頁專輯封面改為純直角。

### 播放頁歌詞
- 換句時整行一起移動，不再一個字一個字鬆散地換行；唱到的字才逐字上浮。
- 修正「邊緣提前發光」：每個字只亮到已經唱到的地方，光暈在字快唱完時才出現。
