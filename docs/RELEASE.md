## Cadenza 2.5.0

**帷幕開場特效「@1」（剪輯影片用）**

**新功能**
- **帷幕開場**：只能手動觸發，專門給剪輯影片用。
  - **觸發**：在歌詞的一句前（或逐字歌詞的某個字前）寫 `@1`。
  - **入場**：到了那一刻，畫面立刻被帷幕整個蓋住，沒有任何漸變，方便剪輯時直接切在這裡。
  - **出場**：帷幕中央出現一顆小星星，以三次曲線（慢－快－慢）放大，直到拉開整個畫面。
  - **配色**：帷幕跟隨背景設定中的「閃光」顏色，拉開的區域跟隨「背景」顏色；拉滿後才換回原本的畫面。
  - **歌詞**：拉開期間，畫面上的歌詞同步淡入。
  - **星形**：較飽滿的五角星，尖角之間的凹角是鈍角（凹角與尖角半徑比 0.5，和參考圖的形狀一致）；內緣有淡淡的陰影和光暈，不會顯得太平。
  - **層級**：帷幕蓋在畫面、字幕和標題之上，但在「顆粒質感」「掃描線」「暗角」等螢幕特效之下，會受這些特效影響。
  - **完全靜止**：帷幕固定在螢幕上，不跟鏡頭移動或震動。
  - **之後擴充**：預留了 `@2`、`@3`、`@4`……，之後新增的帷幕樣式同樣用這種方式觸發。
- **快捷欄**：歌詞編輯框上方的符號列加入 `@1`（帷幕 1），快捷鍵是 Alt+5。

**調整**
- 螢幕特效（顆粒質感、掃描線、暗角、色散、故障）改為最後才畫，現在也會作用在字幕、片頭片尾標題和模糊轉場上，和顯示器的質感一致。
