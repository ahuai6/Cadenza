## Cadenza 2.2.0

**特效符號快捷鍵、白色系介面、MV 結束後回到歌曲原本的樣子**

**新功能**
- **特效符號快捷鍵**：在歌詞編輯框（播放器的歌詞分頁、歌詞工坊）上方新增一排符號鍵，一鍵在游標處插入觸發鏡頭特效的符號：
  - `#1` 最強、`#2` 一般、`#3` 偏弱；
  - 快捷鍵是 Alt+1、Alt+2、Alt+3，數字鍵盤也可以；
  - 插入後可以用 Ctrl+Z 復原；
  - 以後新增其他符號時，各個編輯器會自動出現對應的鍵。
- **白色系介面**：設定 › 外觀新增「淺色色調」，可選：
  - 紙色：目前的暖色調，維持預設；
  - 白色：以前版本的純白色調。
  - 這個選項只在淺色模式下出現。

**修正**
- **MV 比歌曲短**：MV 播完後，會淡出並回到這首歌沒有 MV 時的樣子：
  - 使用歌曲本身的主題，之後切換主題也會正常生效；
  - 不再被封面主題頂替，也不用再手動關一次 MV；
  - MV 的畫面裁切設定也一併解除；
  - 往回拖到 MV 還在播的位置，MV 會照常出現；
  - 匯出影片同樣在 MV 結束處淡出。
- **哥特主題的鎖鏈**：鎖鏈對重拍的反應改為連續的重物擺動：
  - 從靜止平順下沉，約三分之一拍後到最低點，下一個強拍前回到原位；
  - 原本在強拍瞬間跳下、第二拍又突然彈回，看起來像卡頓。
- **播放頁頂部**：移除「正在播放」字樣和重複的專輯名稱，左側的封面與歌曲資訊已經說明了正在播放什麼。
