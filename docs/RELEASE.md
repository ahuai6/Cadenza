## Cadenza 2.12.0

**改進項目第四項（上）：規劃移到背景執行緒，圖層統一**

**改動**
- **規劃不再卡住畫面**：
  - 調整風格、旋鈕放開、改歌詞、換歌時，重新規劃（排版、鏡頭、特效觸發）改在背景執行緒進行。畫面照舊用目前的樣子繼續播放，新的規劃好了才一次換上。
  - 排出來的結果和以前完全相同：字寬仍由畫面這邊用歌曲的字體量好再交過去。
- **背景的視差一致**：
  - 地面格線、頻譜、門框地平線、唱片、節拍光環、碎玻璃，現在和封面一樣，鏡頭移動時統一跟著背景的中景移動。
  - 光環一直從它出來的東西（封面、唱片、地平線）發出。
  - 碎玻璃的碎片取的是板子實際所在處的畫面。
- **反色幾何**：仍會反轉歌詞，但不再反轉字幕、開場與片尾卡和帷幕。
- **結尾**：歌曲淡出到底色時，顆粒、暗角、掃描線、色散、故障也一起淡出，最後不會留下一層顆粒或暗角。
