## Cadenza 2.5.1

**「圓心」歌詞類型真正繞著圓心走**

**修正**
- **圓心不再一路往右**：原本每句只以前一句為圓心，沒有整體的中心，放不下時又退回一般排法往右延伸，所以整體路線還是一直朝右。現在：
  - 每一段有一個固定的圓心，也就是這段的第一句；
  - 之後每句仍繞著前一句擺放，但不會離開圓心太遠，範圍大約是一個畫面寬；
  - 走遠了就優先往圓心的方向繞回來；
  - 繞前一句放不下時，改在圓心周圍找位置，不再退回往右的一般排法；
  - 轉場後的新段落從同一個圓心重新開始。
  - 結果每一步往左、往右的次數大致相當，不會朝某個方向一直走。
- **避讓範圍**：只避開同一段、仍在畫面上的歌詞，不會被早已離場的歌詞佔滿空間。
- **不使用豎排**：圓心類型不再把句子排成豎排，豎排會沿自己的方向跑出圓外。
