## Cadenza 1.3.0

**歌詞格式**
- 分詞只看空格與換行：不再依節拍自動拆字。沒有逐字時間的詞，播放時會依估算的時間逐字前進。
- 副歌改為手動標記：在詞前（或逐字時間後）寫 `#1`、`#2`、`#3`，`#1` 最強。標記只作為記號，不會顯示；所有自動副歌偵測已移除，回到基本重音。
- 括號內的文字當作和聲：和聲與前一個詞同時出現，主詞在左上、和聲在右下，括號不顯示。和聲在自己的時間點淡入，不影響鏡頭與繪製順序。整行只有括號時，照一般歌詞處理。
- 製作頁的說明範例已更新（空格斷詞、`#1` 標記、和聲）。

**運鏡**
- 每種風格都會逐字由左到右跟著演唱移動。很長的詞不再縮小到整個塞進畫面，而是框住一段、跟著唱的字移過去；正在唱的字永遠在畫面內。
- 俐落：逐字快速向右跳步，轉向改為硬切。
- 圓舞：速度適中、逐字平穩跟隨；重新寫了「甩尾過彎」的手感：先從外側切入、再往彎心傾斜，轉向是一條曲線。
- 滑行：從不停下，持續慢慢滑向下一個字；起步時間經過計算，長停頓時只會緩慢前進，不會滑進空白處。轉向更平順。
- 新增「特寫」：與滑行相似，但貼近每一個字，能清楚看到由左到右的移動，也更常用模糊轉場。
- 新的一句可以出現在上一句最後一個字的上方或下方，讓演唱繼續往右走，而不是跳回句首。
- 片尾卡片出現前不再把鏡頭移回中央。
- 修正：很長的尾奏不會觸發閒置鏡頭。原因是尾奏中只有符號、或「間奏」這類標記的行，會讓等待時間重新計算。（「唱片」這類固定在中央的主題，本來就沒有閒置漂移。）
- 修正一個在轉場時間點偶爾出現的背景跳動。

**直式歌詞**
- 直式改為整句、成組出現：連續二到四句直排，之後再回到橫排，不再一句裡直橫交錯。橫排的部分照常轉向。直排的各行以錯落的階梯式排列，彼此靠近。

**律動**
- 「動態」分頁新增「歌詞律動」選項，與運鏡分開，之後可以再加入其他動態。目前的「律動」：唱過的字隨拍子彈起再落下，從詞的第一個字開始像波浪一樣傳下去，重拍最高，每隔一拍左右輕擺。
- 節奏晃動只跟著聽得出來的重音（以小節為基準挑選，並考慮強拍、反拍與切分音），細小的音符交給背景脈動處理。

**新特效**
- 「色散」與「故障」：開關與觸發方式和玻璃特效相同，可以選擇 RGB 色彩或主題色。

**特效改進**
- 玻璃：碎裂時有撞擊凹坑，飛出的碎片更多，細節也重新調整過。
- 字形特效改為毛玻璃模糊。
- 節拍光環：三層光暈，加上錐形光澤的核心，光暈更柔和。
- 星光：更大、層次更豐富，動畫維持原樣。
- 網格移到背景最下層。
- 光點、羽毛、立體線條幾何、節奏線條碎塊遇到重音時一起放慢（共用同一個重音時鐘）。
- 羽毛會落出畫面，再從別處重新生成。
- 立體線條幾何：放到較低的圖層，旋轉跟著節奏，淡出後在別處重新出現。
- 節奏線條碎塊：放到較低的圖層，在空間中漂移，不再抽動。
- 門框地平線：改為靜止。
- 背景線條：加入細微的動態。
- 反色幾何：十字交疊處不再出現菱形缺口。進場方式新增「閃現」，可選滑入、閃現或兩者混用。
- 頻譜跟著實際的頻段節奏變化。
- 歌詞框的內距縮小。

**專輯連播**（專輯頁的「專輯連播」）
- 整張專輯依序播放，像一個不中斷的鏡頭：上一首的畫面在新的一首開始時才溶入，上一首的最後幾句也會留在畫面上，跟著原本的鏡頭漂移、淡出。
- 不加任何會改變歌曲長度的東西：沒有片尾卡片，也沒有結尾淡出。開場標題只用頂部的小標題。
- 所有歌曲都沿用第一首的觀感（顏色、字體、背景）。只改外觀，不影響動態、特效、歌詞或其他設定，也不會寫回每首歌自己的設定，只在連播時生效。
- 標準輸出會提前準備好下一首，所以銜接沒有空檔。Hi-Fi 輸出一次只能處理一首歌，換歌時可能會有短暫停頓。

**播放頁與介面**
- 切歌時，迷你播放器與播放頁的封面、歌名、歌詞會依切換方向淡入淡出（下一首往左、上一首往右）。效果視圖仍使用模糊轉場。
- 播放頁右上角的「⋯」選單新增「搜尋歌詞」與「播放頁設定」：可以在播放頁直接編輯、線上搜尋歌詞、調整時間偏移，並設定歌詞大小、周圍歌詞柔焦、是否顯示翻譯。
- 播放頁歌詞像 Apple Music 一樣：正在唱的一行最清楚，其他行越遠越模糊；滑動瀏覽或滑鼠移到某一行時，那一行會變清楚。
- 展開與收合播放頁時，封面與背景同時到位，陰影不再跳動；播放頁的圓角與主區域一致。
- MV 少裁切模式的切換不再跳動。
- 喜愛的愛心改為白色。

**備註**
- 舊版分析時留下的段落標記仍保留在快取中，以免整個音樂庫重新分析；這些標記已不再用來判斷副歌。
