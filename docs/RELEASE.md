## Cadenza 1.4.2

**強調色**
- 修正：強調色會套用到整句歌詞（沒有空格的一句歌詞會被當成一個詞）。現在只會亮起一句裡的幾個字：
  - 有空格分詞的歌詞，挑一個短詞整個亮起；
  - 沒有空格的歌詞，在句中挑兩、三個字；
  - 英文以整個單字為單位。

**歌詞框**
- 修正：被歌詞框框住的詞有時沒有完整入鏡，尤其是直式歌詞。原因是這個詞之後的字開始唱時，鏡頭就離開了，歌詞框卻還在畫面上。
  - 現在鏡頭移到之後的字時會一併照顧歌詞框，向後拉高並移到兩者上方，完整顯示；
  - 距離太遠、無法同時顧及時，歌詞框會隨鏡頭離開而淡出，不會被切在畫面邊緣。

**直式歌詞**
- 一句直式歌詞接著另一句直式歌詞時，會排在上一句的右邊、左邊或下方：
  - 排在左右時，最上面的字和上一句的第四個字對齊；
  - 排在下方時不另外限制，由鏡頭的邊界自行控制。
