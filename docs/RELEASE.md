## Cadenza 2.9.0

**只有整句時間的歌詞，也按歌手換氣的地方切詞**

**改動**
- 節奏分析分離鼓聲時，同一輪也分離出人聲，讀出每個時刻有沒有在唱。
- 只有整句時間的歌詞（最常見的 LRC）：一句之內人聲停下的地方就是換氣，歌詞在離那裡最近的詞與詞之間切開；短於一口氣的停頓（子音、顫音）不算。一口氣唱完的一句合成一個詞（最多 6 個字）。
- 沒有人聲資料時，和 2.8.0 一樣，只把單獨一個字併到旁邊。這些情況沒有人聲資料：
  - 設定裡關閉了分離；
  - 電腦不支援 GPU 分析；
  - 歌曲還在第一次分析中；
  - 2.9.0 之前分析過的歌曲：需要在歌曲選單裡「重新分析」一次才會有人聲資料。
- 設定項「分離鼓聲」改名為「分離鼓聲與人聲」，說明也一併更新。
