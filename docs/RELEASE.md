## Cadenza 2.5.2

**帷幕清場、圓心歌詞左右平均並清理鏡頭外的舊歌詞**

**改進**
- **帷幕清場**：帷幕（`@1`）出現的那一刻，畫面上所有在它之前就已出現的歌詞，連同下方的譯文字幕，會在帷幕後面一併清除。帷幕拉開後，只會看到寫著 `@1` 的那一句和之後的歌詞，適合剪輯時當作乾淨的新開場。

**修正（圓心歌詞類型）**
- **清理鏡頭外的歌詞**：圓心類型的歌詞都集中在圓的範圍內，鏡頭來回時會一直看到舊歌詞。現在一句唱完後，只要離開鏡頭就立刻移除，鏡頭繞回來時不會再出現。原本「每頁最多四句」的上限照常有效。
- **左右從一開始就平均**：每一句都會放到「目前偏離圓心那一側的另一側」，靠近圓心時左右交替。不會再先連續往右幾次、再突然連續往左幾次。偏離圓心太遠時，上下也一樣往回拉。
- **撞到時換角度**：一句擺放時若撞到別的字，改試另一個角度，不再把它推開。推開會讓它偏離原本的位置，連帶轉向也不再朝外。
