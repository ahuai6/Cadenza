## Cadenza 2.13.0

**改進項目第四項（下）：歌詞改由顯示卡繪製，新增效能數據**

**改動**
- **歌詞由顯示卡繪製**：
  - 歌詞的字形、光暈、投影、厚度邊和失焦，改由顯示卡（WebGL2）一次畫完，再整層放進畫面。
  - 畫面和原本相同：逐像素比較，差別只在字形邊緣的反鋸齒。
  - 每幀在主執行緒上的工作少很多。在沒有顯示卡的測試環境裡，整幀已快約兩成，有顯示卡的電腦上應該更明顯。
  - 匯出影片也用同一種畫法，預覽和匯出一致。
  - 顯示卡不支援或驅動重設時，自動改回原本的畫法。
  - 可在「設定 → 效能」關閉「用顯示卡繪製歌詞」。
- **效能數據**：
  - 「設定 → 效能 → 顯示效能數據」開啟後，特效歌詞左上角會顯示每秒幀數、每幀耗時。
  - 也會列出背景、特效、歌詞、字幕與轉場、螢幕特效各花多少時間，以及顯示卡歌詞和上次規劃的狀態。
  - 用它可以看出在你的電腦上哪一部分最慢。

（2.12.0 已完成第四項的前半：規劃移到背景執行緒、背景視差統一、反色幾何與結尾淡出的修正。）
