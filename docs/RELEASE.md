## Cadenza 2.10.0

**風格系統：外觀和風格分開選，旋鈕精簡成五個，特效分組，字體依歌詞排序**（`docs/STYLE-SYSTEM.md`）

**改動**
- **外觀與風格分開**：
  - 「主題」分頁改名「外觀」：選液態、哥特、封面、影片、唱片，只換背景、配色、字體和特效，歌詞怎麼動不變。
  - 「動態」分頁改名「風格」：六種動態風格——敘事、圓舞、律動、特寫、漂浮、舞台，每種都寫著適合什麼歌；換風格只改歌詞怎麼動，外觀不變。
  - 新歌仍是「封面」外觀加「敘事」風格。
- **推薦風格**：依這首歌的速度、拍號、鼓聲和歌詞密度推薦一個，在選單上標「（推薦）」，不會自動套用。
- **微調旋鈕**：速度、力度、律動、空間、字感五個，每個同時調整幾個細項。原本的鏡頭、歌詞類型、入場、退場和全部細項旋鈕收在「進階」裡，展開後照舊可調；微調旋鈕會乘上細項的值。
- **特效分組**：氛圍、畫面質感、歌詞、哥特系列、唱片系列。哥特和唱片系列的特效在任何背景都能用，分組只標出它們原本為哪個背景設計。
- **字體選單**：依這首歌歌詞實際用到的字排序，能完整顯示的字體排在前面，其他的標出缺字比例。判斷看字體檔本身收錄的字，不看它標的是繁中、簡中還是日文，所以同時收錄正體和簡體的字體，兩種歌詞都排在前面。
- 「殘影色散」改成「歌詞」組的特效「文字殘影」，「字形紋樣頻率」移到字形紋樣特效的設定裡。

**清理**
- 移除沒有作用的「漂移幅度」和「轉向區間」數值，以及一批不再使用的介面文字。

以前存的設定會自動對應到最接近的風格，畫面和以前一樣。
