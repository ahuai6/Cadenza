## Cadenza 1.0.3

### 性能（卡頓的根本原因）
- 快速數字卡頓的真正原因：近景大字在對焦淡入時，每個字每幀都要新建一張模糊字形點陣圖，還要在一張和字一樣大的暫存畫布上合成。這不是數字特有的問題，所有近景大字入場都會發生，只是快速數字最明顯。
- 模糊字形改為固定的「多級預模糊」：每個字只做少數幾級，任何模糊程度都由相鄰兩級混合而成，不再隨模糊程度或鏡頭遠近產生新圖；對焦淡入改為直接疊畫，不再使用暫存畫布。快速數字段落最慢的一幀從約 50 毫秒降到約 8 毫秒。
- 預烘焙：歌曲規劃完成後，利用空閒時間預先製作整首歌所有字形，並在幕後預演每個轉場、字紋與交接動畫各一幀，讓畫布、圖層與封面圖層事先就緒。第一次觸發轉場不再突然卡頓。
- 轉場模糊：模糊濾鏡的開銷取決於所在畫布的大小，原本把小圖畫在全尺寸畫布上做模糊，多花了約二十倍；現在在剛好大小的畫布上處理。
- 渲染測試的每幀繪製時間中位數從約 8–10 毫秒降到 2.5–5 毫秒。

### 介面與過渡
- 播放頁 → 特效歌詞時，正在唱的那句翻譯和羅馬音會平滑移到下方字幕的位置並縮放到字幕大小，不再直接消失。
- 歌曲側欄的分頁改為兩行四欄，「導出影片」不再出界。
- 封面過渡的明暗不再跳變：播放頁的暗化層改由畫面本身繪製，位於背景之上、飛行中的封面與歌詞之下，並隨畫面切換淡出。
- 迷你播放器展開時，背景與封面同步展開。
