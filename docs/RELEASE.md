## Cadenza 2.6.0

**帷幕更從容、字距展開退場、居中鏡頭三句一組、純色背景、全新選色器**

**改進**
- **帷幕**：入場提前約 0.5 秒，換來更長的拉開時間，總長由約 1.25 秒變成約 1.76 秒。
  - 起步速度和以前完全一樣；
  - 多出來的時間都放在快拉滿的時候，越接近填滿越慢；
  - 仍是三次曲線，拉滿的時間點和以前相同；
  - 清場會在帷幕落下的那一刻同步發生。
- **新的退場效果「漸大字距後淡出」**（動態 › 歌詞退場）：
  - 歌詞出現後，字與字的間距慢慢拉開，整句從中間向兩側均勻展開；
  - 離場時淡出，居中鏡頭下則是整組一起淡出。
- **居中鏡頭的位置有規律**：
  - 每三句一組，第一句在中間、第二句在中間上方、第三句在中間下方；
  - 三句一起停留，下一組開始時一起消失；
  - 下一組再從中間開始，如此循環。
- **新背景「純色」**（背景 › 背景模式）：
  - 顏色用「顏色」中的「背景」自由選擇；
  - 可用「壓暗」滑桿調暗；
  - 節拍的小閃動約是其他背景的 2.6 倍明顯。
- **全新選色器**：點任一顏色會打開新的選色面板，有色盤、色相條和色碼輸入。
  - **螢幕吸色**：吸管可以移到視窗外，吸取螢幕上任何地方的顏色，包括其他視窗；
  - **封面取色**：開啟吸管時，色盤上會暫時蓋上這首歌的封面，可以直接從封面取色。
