## Cadenza 1.1.4

- 特效歌詞不再看得到播放頁的邊線：播放頁不再自己畫一圈封邊，而是坐在主區域內側 1 像素，直接沿用主區域本身的邊線與圓角（和音樂庫頁面同一條線）；特效歌詞時畫面蓋滿整個視窗，任何邊線都在它底下。
- 歌詞框改框「小目標」：一個詞（優先選短詞），或很短的詞連同前一個詞，最多幾個字，不再框住一長串；框住時鏡頭維持那個詞平常的遠近，不會為了框而額外推近。鏡頭限位、版面留白、轉場前的完整顯示時間都隨之聯動，並新增回歸測試。
- 副歌入場的重拍：入場之後緊接的第二、第三下重音也會觸發（一下比一下弱）；而且入場與後續重音全部受「重拍觸發靈敏度」控制，靈敏度越低只留越明確的入場，越高觸發越多，閃光、鏡頭衝擊、碎玻璃各依自己的靈敏度取用。
- 從特效歌詞回到播放頁時，標題列的圖示與搜尋框不再提早冒出：它們等畫面在模糊下切換完成後，才隨模糊散去一起淡入；進入特效歌詞時也隨模糊升起一起淡出。
- 播放頁第一次打開不再卡：每首歌載入後，趁空閒把播放頁與畫面在看不見的狀態下先排版、繪製一次（含背景與封面），正式打開時這些都已備好。
