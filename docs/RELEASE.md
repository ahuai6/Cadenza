## Cadenza 2.2.1

**激情的尾奏不再突然安靜、字形紋樣不再跟著鏡頭**

**修正**
- **尾奏畫面變安靜**：歌詞唱完後的尾奏（以及長的間奏、前奏），原本一律當作「休息」處理：鏡頭改成緩慢漂浮，MV／影片背景停止晃動。現在改成看音樂本身的力度：
  - 音樂一直很激情時，畫面持續隨拍子震動，每一拍的震動還會比有歌詞時更強；
  - 從歌詞停下的那一刻起，就開始回應較弱的重拍。原本要等 5 秒，這段是整首歌最安靜的地方；
  - 鏡頭的閒置漂浮會減弱，MV／影片背景不再停下；
  - 音樂真的安靜下來時，畫面仍會像以前一樣慢慢休息。
- **字形紋樣不綁定任何東西**：
  - 不再跟著鏡頭移動，鏡頭的移動、旋轉、震動和切鏡都不會帶動它；
  - 也不再隨重拍停頓；
  - 它只依自己的時間緩慢漂浮、搖擺和呼吸。
