## Cadenza 2.6.2

**「字間距放大淡出」改為字母間距、從退場開始；居中鏡頭每三句一次轉場**

**修正**
- **字間距放大淡出**：
  - **放大的是每個字母、每個漢字之間的距離**：以前逐字歌詞裡一個唱的音節（例如 "hel"、"lo"，或一個時間標記裡的幾個漢字）是一整塊，只有塊與塊之間拉開，看起來像詞距。現在音節會拆成單個字母，每個字母、每個字之間都會拉開；拆開後仍在原本的時間一起出現。
  - **從退場開始**：以前從入場起就慢慢拉開。現在唱完、開始退場的那一刻才開始，在約 2.2 秒內緩緩拉開並淡出；居中鏡頭下則在整組退場時開始。
  - **不再卡頓**：以前拉開的速度跟著當下的拍速計算，而拍速每一拍都可能略有不同，所以間距會一跳一跳。現在用固定的時長，畫面平順。
- **居中鏡頭**：
  - 嚴格依序：每組第一句在中間，第二句在上方，第三句在下方。
  - 每三句之後一次轉場，三句一起在轉場中退場，下一組再從中間開始。下一句緊接著時用快速轉場。
  - 轉場在設定中關閉時，三句仍在下一組開始前一起淡出。
