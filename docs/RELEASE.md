## Cadenza 1.2.0

**音量平衡**（設定 › 音訊，預設開啟）
- 每首歌以 BS.1770 / EBU R128 測量整體響度，播放時加上一個整首固定的增益，讓每首歌聽起來一樣大聲。這不是壓縮器或限幅器：動態與瞬態完全不變；提高音量時只在歌曲自己的峰值餘裕內（保留 1 dB），絕不削波。
- 標準輸出、以及沒有固定音量的 Hi-Fi：作為訊號上的固定增益。
- Hi-Fi 固定音量（比特完美、獨佔）：訊號完全不改動，改由裝置自己的硬體音量調整（只在裝置回報有硬體音量時）；以使用者自己的音量為基準，使用者中途調整也會保留；釋放裝置、結束程式時恢復原本音量。沒有硬體音量的裝置在固定音量下不套用（設定頁會說明）。
- 已分析過的歌只補測響度，不會重新分析整個音樂庫。

**畫面**
- 轉場模糊的霧白改為歌曲自己的背景色，不透明度降低，不再像蓋了一片塑膠板。
- 新場景「滾筒」：同一個詞連續重複時，從第一個開始，每次都放在滾筒的下一面（轉半圈），鏡頭帶彈性地先左後右翻轉半圈再放上歌詞；來不及轉完時，鏡頭帶著那一個詞一起轉。只在時間足夠時觸發，從不讓後面的歌詞遲到；「疾走」優先。翻轉的速度、力道、誇張度分別跟隨「運鏡速度」「重音力道」「轉向幅度」。
- 節拍光環更厚重：每圈都有柔和光暈，重音時中心綻放光暈。
- 羽毛在重音時放慢飄落（約 0.1 秒內減速、停留片刻、約 1.3 秒內平順恢復）。

**純音樂與「唱片」主題**
- 歌曲右鍵選單新增「標記為純音樂」：歌詞改為「純音樂，請欣賞」（六種語言），預設使用新的「唱片」主題（歌曲鎖定時保留原本外觀）。
- 新主題「唱片」：鏡頭固定在正中央、不轉動，只對歌詞小幅聚焦，沒有歌詞時回到正中央；中央是一張完整的大黑膠唱片（封面為標籤）；歌詞一句一句在唱片上下交替出現並完全退場。底色取自封面，其他顏色取封面的對比色。
- 新特效（可在任何主題單獨開啟）：立體線條幾何、節奏線條碎塊、門框地平線、背景線條、反色幾何（置頂，連歌詞一起反色）。「唱片」主題預設開啟前四項。
- 新運鏡風格「置中」，可在其他主題選用。
