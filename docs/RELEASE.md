## Cadenza 1.3.5

**字形紋樣**
- 改成真正「漂浮」的運動，像一片玻璃浮在水中：
  - 在顯示期間緩慢地往自己的方向飄移，每個字的方向都不同；
  - 幾道不同步的慢波讓它上下起伏、左右輕擺，並帶有呼吸般的縮放；
  - 會在縱深方向輕輕轉動，轉動時略為變窄；
  - 會隨背景一起產生輕微的視差。

**碎玻璃**
- 修正：玻璃消失前，碎片飛出後留下的缺口會突然「長回來」。現在缺口一直保持到最後，隨整片玻璃一起淡出。
- 效能：
  - 每塊碎片只讀取畫面中屬於自己的那一小塊；
  - 不再為每塊碎片做裁切；
  - 不再使用 GPU 上代價高的混合模式；
  - 歌曲載入時會預先畫好第一次碎裂，第一次碎裂不再卡頓。

**直式歌詞**
- 鏡頭像跟隨橫排歌詞一樣跟隨直排：
  - 每一列是一個獨立的鏡頭停點，鏡頭沿著這一列往下走，再移到下一列；
  - 遠近以字的大小決定，和橫排一致，不再把整列塞進畫面而拉得很遠。

**哥特背景**
- 剪紙風格的深色薔薇與藤蔓原本接近純黑（這是設計，不是 bug）。現在稍微調灰並帶一點暖色，仍然很深，但不再是死黑。
