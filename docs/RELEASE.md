## Cadenza 1.4.0

**授權**
- Cadenza 改以 **GNU AGPL-3.0** 開源（`LICENSE`）。第三方來源與模型授權見 `NOTICE.md`。

**全新節奏識別引擎：神經網路（移植自 Folia）**
- 新的神經網路引擎在顯示卡（WebGPU）上執行：
  - **Beat This!**（ISMIR 2024）找出每一拍與每個小節的強拍；
  - **HTDemucs** 分離出鼓聲，從鼓聲本身讀出底鼓、軍鼓、鈸的每一下。
- **更準的節奏**：
  - 速度與小節不再靠推算。小節長短可以不一樣，拍號變化也能跟上。
  - 6/8 這類複合拍子，以及被數成兩倍速的慢歌，會換算回聽起來的拍子。
  - 每拍的重音按「突起」和「周圍有多響」決定。
  - 只有長音鋪底、沒有鼓的段落（例如管樂前奏），以及模型拿不準的自由節奏段，都不會觸發律動和重拍特效。
  - 鼓聲分離後，鏡頭、律動和觸發特效都跟著真正的鼓點走。
- **一個介面**：兩個引擎輸出同一份分析資料。鏡頭、特效、律動等所有功能不用改，就自動用上新引擎的結果。
- **自動退回**：沒有可用的 GPU、找不到模型或執行失敗時，自動改用原本的內建分析，不會報錯。
- **設定**：在「設定 → 節奏識別」可以：
  - 選擇引擎：神經網路（自動）或內建；
  - 開關「分離鼓聲」：更準，但較慢，執行時約佔用 350 MB 顯示記憶體；
  - 查看目前用哪張顯示卡分析，或無法使用的原因。
- **模型**：兩個模型檔（約 130 MB，皆為 MIT 授權）隨安裝包附帶，不需要另外下載；每個檔案都以 SHA-256 校驗。
- **重新分析**：因為分析資料格式更新，音樂庫會在背景用新引擎重新分析一次。
