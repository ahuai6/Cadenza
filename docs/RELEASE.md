## Cadenza 1.3.1

**運鏡**
- 所有運鏡風格都會跟著正在唱的字一路往右走：唱到的字會在畫面中央略偏左，右邊留出空間。很長或連在一起的幾個詞不會為了整個塞進畫面而拉遠，而是維持原本的距離跟過去。
- 俐落：和滑行一樣的跟隨方式，只是更快、更利落。轉向不再是閃一下的硬切，而是隨移動一起轉。
- 圓舞：每次移動都走弧線，先往外再切進彎道，並朝彎道傾斜。轉向略落後於移動，稍微甩過頭再回正，像過彎一樣。
- 滑行：不再停下來。移動以原本的速度出發，落地時仍在前進；唱完最後一個字之後也會繼續慢慢往前，並在下一句前就把鏡頭帶到位。在等待演唱的空檔不會先往前漂。
- 特寫：遇到歌詞框不再停住、拉遠（特寫模式下不使用歌詞框）。長歌詞也不會慢慢拉遠，會保持特寫的距離，並在最後一個字唱完後才離開。
- 修正：歌詞出現到一半時，鏡頭會輕微往右移動一下。原因是鏡頭在歌詞開始唱之前就先往前漂；現在漂移會等到字唱完才開始。
- 修正：轉場時間點附近偶爾出現的背景跳動。

**節奏**
- 一直很重的流行鼓點（每拍都有大鼓）現在每一拍都會震動鏡頭，強拍最重。以前因為每一拍都一樣重、沒有哪一拍特別突出，經常只震個一兩下。細小的音符（例如腳踏鈸）仍然只交給背景脈動。這項改進不需要重新分析音樂庫。

**歌詞**
- 新增「歌詞類型」設定（動態分頁），像運鏡風格一樣可以選擇：
  - 流動：目前的呈現方式，逐字沿著路徑在空間中出現，大小錯落；
  - 整句：整句一起出現、統一大小，隨著演唱逐字點亮。
  進場、退場與未唱歌詞的顯示方式，都是這個類型底下的設定。之後可以再加入其他類型。
- 移除了 1.3.0 的「歌詞律動」選項。
- 每頁最多累積十句就會轉場清空：從第八句起，遇到可以轉場的空檔就清空；到第十句時，即使只有很短的停頓也會清空。連一點停頓都沒有、一句接一句唱的歌，會在兩句的交接處做一次很短的模糊轉場。

**特效**
- 節拍光環：
  - 在「唱片」「封面」主題，或開啟了門框地平線、地面網格時，光環從這些背景元素的後方發出（封面之後、唱片之後、地平線的消失點）。
  - 沒有背景元素時，畫面中央會出現一團像低音喇叭的「光團」，隨低音往外推，光環從它的邊緣發出。
- 碎玻璃：移除了撞擊凹坑，碎裂中心本身也是玻璃，會最先飛出。
- 字形毛玻璃特效改為以較小的尺寸處理，繪製時間大約減半，外觀沒有變化。

**修正**
- 播放片尾時離開特效歌詞頁面，片尾字樣不會再留在畫面上蓋住小歌詞。
