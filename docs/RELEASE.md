## Cadenza 1.1.0

### 播放頁與特效歌詞
- 播放頁改為佔用主區域（保留側欄與標題列），從迷你播放器的底邊向上覆蓋展開，頂邊、兩側與圓角各有自己的曲線；全螢幕時佔滿整個畫面，歌詞區略為右移，游標靜止時頂部列與封面下方的控制項會淡出。
- 播放頁與特效歌詞之間改為全螢幕模糊轉場：畫面整體失焦，在最模糊時切換，再重新對焦，不再有閃爍、封面變黑或跳變（MV 模式同樣適用），效能也更好。
- 特效歌詞預覽預設為 16:9（匯出時仍可調整）。
- 播放頁進度條上方顯示半透明的音質標籤。

### 音樂庫
- 歌曲列表顯示「音質 + 格式」標籤（例如「無損 FLAC」「Hi-Res WAV」）：標準（綠）、高品質（藍）、無損（紫）、Hi-Res（金）。依無損與否、取樣率與位元深度判斷。
- 正在播放的圖示改為讀取節奏系統的頻譜，即時反映歌曲本身的動態（第一次開啟會在背景重新分析音樂庫）。
- 新增「定位正在播放的歌曲」按鈕，捲動到該歌曲並短暫高亮。
- 歌曲面板移除「片尾」設定，片尾資訊直接跟隨歌曲的中繼資料（歌名、演出者、作曲、作詞）。
- 各頁面、列表與卡片加入統一的淡入效果。
- 全面整理介面文案，統一用語與語氣；「排序」「來源」等標籤改為橫向排列。

### 效果與運鏡
- 影片背景在伴奏段（長時間停頓）會依運鏡速度緩慢歸正、置中並逐漸取消暗化；下一句歌詞前的模糊轉場中恢復暗化，沒有跳變。
- MV 預設不降低飽和度、暗化略減；設定頁新增「MV 畫面」（暗化、柔焦、飽和度、少裁切）。影片背景新增「少裁切」開關：背景保持水平不隨鏡頭旋轉，只放大到剛好不露邊。
- 碎玻璃改為重擊碎裂：裂紋瞬間擴散，碎片從撞擊點向外飛散並朝鏡頭飛近。
- 閃光、反色與碎玻璃改在正拍重音上觸發，並優先落在段落進入（例如進入副歌）的那一下。
- 修正歌詞入場時字形上下區域的明暗跳變（模糊字形與清晰字形使用相同的受光漸層）。
- 修正全螢幕模糊轉場結束時的抽動（模糊副本與畫面精確對齊）。
- 歌詞依「空間縱深」設定加入立體傾斜。
- 新增依場景自動選擇的排列方式：歌詞密集、語速很快時，歌詞與鏡頭一路向右、隨節拍起伏前進（疾走感）；架構方便日後擴充其他場景。
- 新增「律動」設定（範圍更大），獨立控制跟隨小拍與旋律的背景脈動、閃爍與輕顫；「重音力道」只控制重拍與重音的效果。
