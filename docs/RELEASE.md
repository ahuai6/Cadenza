## Cadenza 2.16.0

**第一輪 C：播放頁歌詞顯示，以及你回報的幾個問題**

**播放頁歌詞**
- **逐字填色**：下一個字緊接著開始（沒有空隙或空隙很短）時，上一個字在下一個字開始前就填滿，不再拖到下一個字底下。
- **逐行歌詞換行**：只有整行時間的歌詞，切到下一行時不再重播一次由左到右的掃過，整行直接亮起。
- **翻譯與讀音**：
  - 順序改為先翻譯、後讀音（和 AMLL、Apple Music 相同）。TTML 的解析本身沒有對調（`translations` → 翻譯、`transliterations` → 讀音），之前看起來「反了」是因為我們把讀音排在翻譯上面。
  - 讀音比翻譯淡。
  - 和原句一模一樣的讀音不再顯示（例如英文歌的讀音就是原句）。
  - 設定裡新增「顯示讀音」開關。
  - 翻譯裡括號中的內容另起一行，以和聲的樣式顯示；特效歌詞的小字幕也一樣。

**特效歌詞**
- **和聲不出界**：鏡頭取景時把和聲也算進去，和聲不會再落在畫面外。

**歌曲列表**
- 有 TTML 歌詞的歌不再被當成沒有歌詞；改為只在缺少歌詞時顯示「缺歌詞」標記。

**效能與穩定**
- **背景**：封面主題的背景改為在低解析度先合成、再一次放大畫出；靜止的封面（含陰影、光澤、邊框）快取起來，不再每幀重畫。在 2160p 下背景的耗時約少了三成。
- **歌詞多時掉幀**：字形快取與顯卡字形圖集依畫面大小加大，減少大量歌詞時反覆重建字形。
- **自動解析度**：顯示卡跟不上時，可以降到低於一個 CSS 像素（最低 0.7 倍）。
- **「きゃきゃきゃ……」一行卡住、背景變黑**：字形畫布改為 CPU 端，上傳到顯卡時不再需要從顯卡讀回，這可能是長字放大時顯示卡逾時、畫面變黑的原因。這台機器上沒有重現，請在你的電腦上確認。
