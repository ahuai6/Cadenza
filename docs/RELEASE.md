## Cadenza 2.9.2

**規整光環尺寸收窄、歌詞入場更快**

**改動**
- **字環的「規整光環」**：大小改以單個字的高度計算（以前按整個詞，詞越長光環越大）。外圈直徑在字高的 1.3 倍到 2.5 倍之間，每個詞隨機落在這個範圍內；展開時從最小開始，隨節拍的微微呼吸也不會超出上限。
- **歌詞入場**：
  - 各主題預設的入場時間縮短約三成。
  - 「入場時間」旋鈕的最小值從 0.4 降到 0.15，可以設得更快。
  - 各種入場方式的最短時間也一併降低，所以旋鈕調得很小時確實會變快，不會被下限卡住。
  - 詞提前出現的時間維持和以前一樣，入場變快不會讓字更晚出現。
