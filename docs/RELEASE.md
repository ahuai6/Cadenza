## Cadenza 1.4.1

**顏色與強調**
- 「閃光」的預設顏色改為從背景元素的顏色取一個更淡的同色調，不再是白色。例如哥特背景是淡玫瑰色，封面背景是封面主色的淡色。
- 特效歌詞約每三、四句會隨機挑一個詞，用閃光的顏色強調，並帶一點柔和的高光。

**節奏**
- 所有場景粒子都接入重音慢放，在重拍時懸停一下再繼續漂浮，包括：
  - 哥特背景的花瓣與薔薇；
  - 光點、散景光斑；
  - 液態背景的流動；
  - 字形紋樣、唱片主題的線條與門框。
- 使用神經網路引擎分析的歌曲，慢放直接按每拍測得的重音強度觸發。

**轉場與鏡頭**
- 只有在上一句能完整唱完的情況下，才會觸發全屏模糊轉場。時間不夠時不再模糊，而是直接清掉鏡頭外看不見的歌詞，同一頁上的歌詞最多十句。
- 模糊轉場期間，鏡頭的抖動、重拍震動和律動擺動都會完全停住。
- 修正：一句歌詞後面長時間沒有歌詞時（例如歌曲最後一句），鏡頭有時會在這句唱完後才到位。
- 直式歌詞的鏡頭再拉近一些。

**歌詞框**
- 歌詞框會按歌詞實際的傾斜、浮動和縮放框住，但刻意不完全貼合，保留自然感。
- 修正：很傾斜的歌詞有時會出界。
- 修正：框直式歌詞時留白過大。
- 被框住的詞，鏡頭會拉遠讓它完整入鏡，這次正式保留這個效果。
- 歌詞框的出現頻率降低，大約每五句一次。

**介面**
- 專輯的曲目編號改為在封面位置正中，字也放大。
- 播放頁的和聲改為像 Apple Music 一樣，以較小的一行顯示在歌詞下方，並隨演唱逐字亮起。
- 修正：特定情況下（例如從工作列圖示結束後再開啟），歌曲列表會卡住無法點擊。
- 修正：左下角「正在分析節拍」會停在 1。現在會顯示目前這首歌的分析進度。神經網路分析的時間依歌曲長度設上限，逾時就改用內建分析，不會再卡住整個分析佇列。

**畫質模式**（設定 → 效能）
- **默認**：所有效果照設計呈現。
- **優化**：特效歌詞不再使用高斯模糊和反射：
  - 模糊改用低解析度多級縮放的方法（Dual Kawase）；
  - 玻璃折射改用低解析度畫面；
  - 畫面幾乎相同，轉場時的負擔約減少三成。
- **精簡**：所有頁面和特效歌詞都不使用模糊、反射和其他耗效能的效果，低配電腦也能順暢使用。
- 導出影片一律使用完整畫質。

**節奏識別**
- 新增「僅神經網路」模式，不改用內建分析：
  - 無法執行或逾時的歌曲會標記為分析失敗，並以速度網格播放；
  - 播放器等待時逾時的歌曲，之後會在背景重新分析。
