## Cadenza 2.14.0

**第一輪 A：播放核心與性能**

**改動**
- **畫面更流暢**：播放時的時間以前每 10～23 毫秒才跳一次，畫面常常一兩幀不動再跳一下，所以幀數再高看起來也像不到 60 幀。現在改讀喇叭實際發聲的時間，每一幀都平順前進，也和聽到的聲音對得更準。
- **起播更快、更少卡住**：
  - 已分析過的歌，建立場景（斷詞、字體、規劃）和解碼音訊同時進行，不再一個等一個。
  - 音訊環境和斷詞字典在啟動後就先準備好，第一首歌不必等。
  - 預先準備的歌從四首減為三首，少佔記憶體。
- **特效鏡頭卡頓**：自動調整解析度時，以前會在一幀之內把所有字重做一遍，可能卡住一秒並出現黑畫面。現在先在空閒時間把新解析度的字做好，再一次切換，切換後也不會來回跳。
- **特效歌詞播放中，背景分析讓路**：音樂庫的分析在兩首歌之間暫停，把顯示卡留給畫面；離開特效歌詞或暫停時繼續。
- **Hi-Fi 直通**：指定的裝置被拔掉或停用時，自動改用系統預設裝置繼續播放，裝置回來後再切回，不必再手動選一次。
- **邊播邊分析**：左下角改為顯示「邊播邊分析：這首 xx%」，不再看起來像在掃描音樂庫。
- **進度條**：時間只算到音樂結束，片尾不再讓時間超出總長。
- **效能數據**新增：
  - 「上次起播」：讀檔與解碼、節奏、建立場景（封面、斷詞、字體、規劃）、顯示各花多少毫秒。
  - 「兩分鐘內最長卡頓」：卡了多久，以及當時是否在做新字形、改解析度或換規劃。

如果還有卡頓，請開啟「設定 → 效能 → 顯示效能數據」截圖，就能看出是哪一段。
