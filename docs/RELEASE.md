## Cadenza 2.1.0

**邊播邊分析節拍、歌詞寫入音樂標籤、模糊轉場與鏡頭邊界修正**

**節拍分析：邊播邊分析**
- **不用再等**：還沒分析過的歌按下就播。
  - 開頭 30 秒先快速分析，約 0.3 秒。
  - 節拍沿開頭的速度與小節延伸到整首，特效從第一秒就跟著拍子走。
  - 完整分析在背景進行，可以用神經網路引擎和鼓聲分離，不受「播放器在等」的時間限制。
- **無縫換上**：完整分析完成後會自動換上。
  - 特效歌詞正在播放時，等下一個模糊轉場的最模糊處再換，看不出來。
  - 附近沒有轉場可等，就用不到一秒的交叉淡化換上。
- **快取只存完整分析**：開頭的快速分析不存，只存完整分析。匯出影片和工坊也一律等完整分析。
- **新設定「分析時機」**（設定 › 節奏識別）：
  - 「邊播邊分析」排第一，是預設；
  - 「分析完再播放」保留原本的做法。

**歌詞寫入音樂標籤**
- **寫進檔案**：編輯歌詞後按儲存，歌詞直接寫進音樂檔案的內嵌標籤，支援 MP3、FLAC、M4A、Ogg、WAV 等。
- **自動解除佔用並重載**：
  - 寫入前會先讓播放器放開檔案，Hi-Fi 輸出也一樣；
  - 寫入時先改一份暫存副本，完成後再替換原檔，中途失敗也不會損壞檔案；
  - 寫完從原來的位置繼續播放。
- **新設定「儲存位置」**：在歌詞編輯面板中，可選寫入標籤（預設）或存成旁邊的 `.lrc`。
- **不支援時改存 `.lrc`**：檔案格式不支援標籤時，會自動改存 `.lrc` 並提示；檔案被其他程式佔用時也會提示。

**修正**
- **模糊轉場的短暫抽搐**：從根本處理了四個原因：
  - 一次縮小太多倍造成的鋸齒閃爍，改為逐級減半取平均；
  - 模糊快消失時露出低解析度那一層，現在模糊半徑換算後設有下限；
  - 轉場途中自動調整解析度，導致字形快取重建，現在轉場前後不再調整；
  - 切點後第一次繪製的卡頓，現在提前預熱。
  - 背景震動動畫沒有改動。
- **逐字歌詞的特效符號**：`#1`、`#2`、`#3` 這類符號不再被吸附到附近某個固定的拍點。符號寫在哪個字的時間上，就在那個字唱出時觸發，可以精準卡點。只有整行時間的歌詞，因為每個字的時間是估計的，仍會對齊最近的重音。
- **歌詞跑出鏡頭外**：16:10 等比例下，歌詞偶爾會跑到畫面外。
  - 現在整首歌的每一刻，正在唱的那個字都保證在安全框內；
  - 判斷的是字本身的範圍，而不是整個詞的中心；
  - 16:9、16:10、1:1、9:16 都有測試。
