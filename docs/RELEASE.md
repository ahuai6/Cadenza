## Cadenza 2.3.0

**歌詞會往回走了：每次轉場換一個方向，上下左右輪流出現**

**改進**
- **每次轉場後反方向**：
  - 原本每個段落都從頭往右排，所以歌詞幾乎從不往回走；
  - 現在每次模糊轉場後換一個方向：往右、往左、往右……；
  - 每兩次轉場換一次上下：新段落輪流出現在前面歌詞的上方或下方；
  - 四個段落一輪，上下左右都會有規律地出現歌詞。
- **往左的歌詞不逐字跟隨**：
  - 往左走的段落中，每一行從前一行開頭的左側開始，位於上一列或下一列，一行接一行往左排；
  - 這些行整行取景、停住，鏡頭不沿著字往右跟；
  - 鏡頭只會一行一行往左移，不會在一行裡往右走又折回；
  - 判斷依據是畫面上的實際位置：只要一行明顯排在前一行的左邊，就整行取景。
- **長句仍往右**：太長的句子若整行入鏡，字會縮到不到平常的一半；這種句子仍往右排並逐字跟隨，避免字太小。
