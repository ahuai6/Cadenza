## Cadenza 2.11.0

**節奏引擎本機加速：拍點與分軌模型改用顯示卡原生執行（Windows：DirectML）**

**改動**
- **本機加速**：節奏引擎的兩個神經網路（拍點 Beat This!、分軌 HTDemucs）可以改由桌面版自己的 ONNX Runtime 執行，不再經過瀏覽器的 WebGPU。Windows 用 DirectML（任何支援 DirectX 12 的顯示卡），macOS 用 Core ML；顯示卡無法使用時自動改用 CPU。
- **設定 → 節奏引擎**：
  - 「執行位置」：本機加速（自動）或瀏覽器 GPU。
  - 第一次使用要按「下載」取得模型（約 356 MB，存在本機；每個檔案都會核對 SHA-256），下載完成前照舊用瀏覽器 GPU。
  - 下載後可選「裝置」：自動（GPU 優先）或僅 CPU。
  - 狀態列顯示目前用的是哪一種（例如「本機（DirectML）」）。
- 只換「跑網路」這一步：頻譜、切段、拍點與鼓點、人聲的判讀完全不變，所以結果和以前一致。
- 模型第一次載入時會花一段時間最佳化（每台電腦、每種裝置一次），之後不到一秒就能開啟。推理在獨立的背景行程執行，閒置兩分鐘後自動結束、釋放記憶體。

**注意**
- 本機加速失敗（沒有模型、驅動不支援等）時，會自動回到瀏覽器 GPU 或內建分析，不影響播放。
- 設定從之後分析的歌曲開始生效；已分析過的歌曲可在音樂庫重新分析。
