# 導演（`src/director`）

導演把一首歌一次規劃成不可變的 `ScenePlan`（版面、鏡頭、轉場、觸發、標題），播放時只按時間求值。總覽在 `docs/ARCHITECTURE.md`。

## 規劃（強前瞻）

`plan(input) → ScenePlan`，輸入是歌詞模型、量好的字、節奏地圖、主題。規劃順序：
1. **時間正規化**（lyrics）：快於感知門檻的連續單位合併為一組。
2. **歌詞框**：先決定哪些詞有框，框的外輪廓計入該組的佔位。
3. **居中鏡頭**（`centerLayout`）：每組最多佔三列（以換行後的列數計：三句短句；一句換成兩列的加一句短句；三列以上的長句單獨一組），嚴格依序放在中間、上方、下方；每組之後一次轉場（`reason: 'layout'`，下一行緊接時用快轉場），整組在轉場中一起退場。關閉轉場時，整組改在下一組第一句出現時一起淡出（`leaves`，由 `plan.ts` 在分段之後套用）。
   **字間距放大淡出**（`tout: 'spread'`）：排版時把多字母的單位（一個唱的音節）拆成單個字母，各字母沿用音節的時間；從該行第一個詞的入場動畫完成起，字母間距持續緩慢放大，直到該行消失（唱完後 2.2 秒；居中鏡頭下是整組退場時），最大約字高的 0.2 倍；同時淡出，前段很少、最後才多（`1 − x³`），唱的時候仍清楚可讀（`words.ts` 的 `SPREAD`、`SPREAD_GAP`）。時長不隨當下的拍速變化，否則拍速逐拍變動時間距會跳。
   **排版**（歌詞類型 `lyrictypes.ts` 決定：`stack` 往上下排的機率倍數，「流動」1.45；`orbit` 圓心排法，每段以第一句為圓心（`orbO`），每句以前一句的中心為圓心、選一個角度放上去，但不離開段落圓心約一個畫面寬（`ORBIT_RANGE`），角度一律朝「目前偏離圓心那側的另一側」（靠近圓心時左右交替），所以從一開始左右就平均；撞到不推開而是換角度；唱完並離開鏡頭的行立即移除（`plan.ts` 的 `sweepUnseen`）；繞不下時改在圓心周圍放（不退回一般排法）；避讓只看同段、仍在畫面上的行；不用豎排；偶爾轉向，轉向時只讓字頂朝外，角度在 ±100° 內；`depth` 縱深倍數，圓心 2.4，詞內取平方根）：沿路徑擺字（換行、轉折、回折、新段落），不重疊、相鄰距離有上限。每次轉場（新段落，包括鏡頭自己加的轉場：`plan.ts` 會帶著它們重排，最多三輪，直到不再新增）換一個行進方向：往右、往左、往右……，同一段內不再折返，每兩次換一次上下（新段落在前面歌詞的上方或下方），四段一輪。往左時每一行從前一行開頭的左側、上一列或下一列開始（`back`），每步明顯往左（新行中心在前一行開頭的左側），一行接一行往左，任何長度的行都可以往左排；往右的段落裡，排到上下列的行中心不會比前一行更左（`onward`）。往左的行（`west`：往回排的、往左段落的第一行、以及畫面上明顯在前一行左邊的）由鏡頭以「懸停」風格取景（`Stop.hov`）：每組詞一個停點、鏡頭在詞組中間上方，往畫面左方（行的走向）微微領先並緩慢漂移，不逐字跟隨。**不往一個方向走太遠**（疾走場景除外）：段落記下起點（`secO`）與尺度（`secR`：第一行寬與一個畫面取大者）。離起點超過 `WANDER`（1.8）倍尺度的一半後，下一行一律放在前一行的上方或下方（避開再前一行那一側，三行上下交錯），中心比前一行稍微往起點方向退回；撞到時往上、下或往起點方向推開，不再往前推；豎排之後的下一欄也改放在往起點的那一側；行首不再轉折。超過 `WANDER` 倍尺度的行視為放不下：依序改試下方、（往右的段落）右方，仍不行就快速模糊轉場；連快速轉場的空檔都沒有時，才在原頁繼續（`roam`），且只有真的重疊時，只要有 0.2 秒空檔就仍然模糊轉場。**同畫面最多三行**（`PAGE_LINES` = 3：當前一行和前兩行）：第 4 行出現時最舊的一行立即淡出（鏡頭看得到時 0.5 秒，看不到時直接移除）；排版避讓也只看同段仍在畫面上的這幾行，舊行的位置可以再用。圓心排法所有角度都放不下時，改為模糊轉場、開新的圓。
4. **段落轉場**：長間奏 → 模糊轉場；峰值對齊下一段真正的起點（含弱起），時長以拍計、提前開始。
5. **鏡頭**：鏡頭風格是策略（`CameraStyle`）：硬朗切換、平滑滑行、華爾滋。共用的規劃器：
   - 每組字一個取景目標（構圖沿演唱方向留出前方空間，不鎖死中心）；
   - 移動以「位移疊加」構成：`p(t) = p0 + Σ Δᵢ·eᵢ(t)`，相鄰移動自然銜接、速度連續；
   - **約束在規劃中解決**：正在唱的字必須在安全框內（推遲出發或放寬取景）；超過最遠位移閾值就改排模糊轉場；
   - 停留時沿演唱方向緩慢漂移（有上限）；
   - **依遠近受力**（`project.ts` 的 `depthFeel`）：畫面本身的晃動、搖擺、震動與傾斜，依每個字的縱深按視差倍數的平方作用（近的較多、最多 1.3 倍，遠的較少、最少 0.35 倍）；推近（縮放）只對遠處減弱。逐字的節拍抖動也依縱深縮放。歌詞因此各自隨距離反應，不像同一個平面圖層。
   - **沒有歌詞的長段落**（前奏、間奏、尾奏）：休息與否看音樂的力度（`driveAt`：歌曲內相對音量，取前後約一秒的平均），不只看有沒有字。音樂在推進時，閒置漂浮減弱、不讓背景休息（`rest`），每拍的震動加強；從歌詞停下起（`wordlessK`，閒置窗口的 `g`）就回應較弱的重拍。音樂安靜時才慢慢休息。
   - **歌詞框完整入鏡**（`fit.ts`）：在鏡頭實際走的取樣路徑上（整首歌，不只有框的段落）檢查每個框（含邊距）和**正在唱的那個字的方框**（`singing()`：取自該字的單位方框，不是詞的中心），有超出安全框的就平移、必要時拉遠（最多到 0.62 倍），拉遠提前開始、延後結束，再以高斯平滑，不跨切鏡；拉遠的上限只由框決定（`kf`），正在唱的字永遠要入鏡；需要拉得更遠的框提前 0.5 秒淡出。對所有鏡頭風格、比例（16:9、16:10、1:1、9:16 都有測試）、橫排直排一視同仁。
   帷幕：歌詞裡的 `@N`（N 為 1–9）記下它所在時間戳的時間（逐字歌詞是那個字的），不顯示；渲染時（`render/curtain.ts`）那一刻帷幕 N 立即蓋住畫面，停一下後以三次曲線拉開。帷幕用閃光色，拉開處先是背景色再換回畫面，歌詞隨之淡入。帷幕畫在畫面與字幕之上、螢幕特效之下，固定在螢幕座標。帷幕的時間（提前量、停頓、拉開時長與曲線）在 `director/curtains.ts`，畫面與清場共用；帷幕 1 提前約 0.5 秒落下，起步沿用原本的三次曲線，在 0.3 處轉為較長的三次減速，速度連續、拉滿時間不變。帷幕落下的同時清場（`plan.ts` 的 `applyCurtains`）：在它之前開始的每一行都在那一刻結束，連同譯文字幕。新增帷幕只要在 `CURTAINS` 加一項。
   歌詞框：歌詞裡詞前的 `$1`（解析時換成一個私用字元，不顯示）會在那個詞外加框，不受「歌詞框線」開關與特寫限制；自動挑選的框避開這些行。
6. **效果事件**：閃光、衝擊、碎玻璃、光環……全部由節奏地圖 `select()` 而來。歌詞裡的副歌標記（`#1`/`#2`/`#3`，`cues.ts` 的 `markedEntries`）：標記帶著自己的時間戳（所在音節的逐字時間，或只有標記的時間戳）時是 `exact`，就在那個時間觸發，不吸附到附近的拍；只有整行時間、字的時間是估計的，才吸附到最近的重音。編輯器插入的符號都來自同一份清單（`lyrics/parse.ts` 的 `CUE_SYMBOLS`，介面的 `ui/cues.tsx` 依它生成按鍵與 Alt 快捷鍵），新增一種符號只需在清單與解析中各加一處。**沒有頻率上限**：靈敏度選中的每一個重音都會觸發（同一個擊打不重複算），設定頁附光敏性癲癇提醒。為了讓每幀的成本有界，碎玻璃在下一塊碎裂後半秒內淡出，同時最多約兩塊。
7. **標題**：前奏夠長 → 片頭標題卡；不夠 → 頂部小標題，不影響主歌詞。結尾標題卡。

`evaluate(plan, t, signals) → SceneFrame`：相機姿態（基本路徑 + 動態層：紙盆彈簧、手持漂浮、閒置漂移、衝擊）、每個字的狀態（入場進度、模糊、透明度）、效果參數。純函式，可在任意時間取樣（導出、預熱、測試）。

**投影**：相機姿態 `{x, y, zoom, roll, depth, yaw, pitch}`；字的深度視差以畫面尺度的焦距計算；傾斜是有界的透視（|yaw|,|pitch| ≤ 4°，畫面座標正規化後計算），與字的世界座標無線性耦合。繪製順序由規劃時決定的穩定鍵決定。

## 歌詞的清理機制（2.21 整理）

畫面上的歌詞由下面幾種機制收掉，依觸發的先後列出。除了「離開鏡頭即移除」只用於圓心排法，其餘每種風格都有。

| 機制 | 位置 | 何時觸發 | 怎麼收 |
|---|---|---|---|
| 段落轉場 | `layout.ts`（passages） | 長停頓、新段落、排不下的行 | 全畫面模糊轉場，轉場後是新的一頁 |
| 擁擠時的快速清場 | `layout.ts`（CROWD） | 同一頁的字太多，且有短暫停頓 | 快速模糊轉場 |
| 看不見就移除 | `plan.ts` applySweeps | 擁擠又沒有空檔轉場 | 鏡頭看不到的行直接移除 |
| 同頁最多三行 | `plan.ts`（PAGE_LINES） | 第四行出現 | 最舊的一行 0.5 秒淡出；鏡頭看不到就直接移除 |
| 離開鏡頭即移除 | `plan.ts` sweepUnseen（只用於圓心排法） | 唱完的行一離開鏡頭 | 直接移除 |
| **新舊重疊就淡出（2.21）** | `plan.ts` fadeOverlapped | 新出現的詞與仍在畫面上的舊行重疊超過較小框的 30% | 舊行從那一刻起 0.25 秒淡出；正在唱的行不受影響 |
| 幕布記號 `@N` | `plan.ts` applyCurtains | 記號的時間點 | 之前的行全部收掉 |
| 字本身的淡出 | `words.ts` | 唱完變暗，整行結束後淡出 | 逐字 |

另外，和聲跟著它的主詞：主詞還在，和聲就在；只有主詞被上面任一機制收掉時，和聲才一起消失（繪製時，主詞或和聲任一在畫面內就會畫）。

## 鏡頭程式（`director/cameras.ts`，3.5.0）

鏡頭風格是登記表裡的一筆「程式」，記著它和別的鏡頭不同的地方（特徵）。規劃器（`camera.ts`）、排版（`layout.ts`）、入場（`entry.ts`）、清場（`plan.ts`）與渲染只讀特徵，**不讀鏡頭的名字**；所以任何風格可以配任何鏡頭，新增一種鏡頭是一次登記，不是在導演裡到處加 `if`。

| 特徵 | 意思 |
| --- | --- |
| `smooth` | 移動有緩動與圓角（只有硬切的「俐落」是 false） |
| `curves` | 走弧線、到達時畫面擺動（圓舞一族） |
| `hover` | 停在詞組中間上方，不逐字跟隨 |
| `close` | 每個字都拉近（自己的遠近） |
| `held` | 停在中間、整行取景、不排直欄；有自己的規劃器（置中） |
| `follow` | 長詞怎麼走：`punch` 快速衝到每個字、`step` 穩定一步步、`run` 不停 |
| `cruise` | 移動保持進入時的速度，不在每站減速 |
| `lead`、`drift` | 提前出發的量（120 BPM 一拍的比例）、停留時漂移的速度 |
| `cone`、`coneRoll` | 到達時畫面的前傾與滾轉 |
| `kicks` | 重音落點時畫面彈一下 |
| `lookahead` | 路徑往下一站平滑的前瞻秒數；0 表示不平滑（硬切或特寫） |
| `flashRise`、`flashPeak` | 重音閃光的上升時間與峰值 |
| `soften` | 規劃好的路徑再柔化多少：位置、滾轉、遠近（秒） |

六個內建程式：俐落（punch）、圓舞（waltz）、滑行（glide）、特寫（close）、懸浮（hover）、置中（center）。數值見 `cameras.ts` 的登記；`cameraProgram(id)` 遇到不認識的 id 回傳滑行。

**新增一種鏡頭**：在 `cameras.ts` 用 `registerCamera({...base, id, label, …})` 登記，只改和 `base` 不同的特徵；需要完全不同的走法時，第二個參數給它自己的規劃器（像置中）。在字典加 `cut.<id>`，在 `docs/COPY.md` 加名字。設定頁的鏡頭選單由 `cameraPrograms()` 列出，不必改介面。

## 轉場的時機與樣子

導演只決定**什麼時候**轉場（`passages.ts`：長停頓、新段落、擁擠、排不下），以及每段的上升、峰值（切鏡）與清除。**轉場看起來怎樣**在渲染層（`render/transitions.ts`，見 `docs/parts/render.md`），由風格的 `transFx` 選。
