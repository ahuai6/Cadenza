# 导演（`src/director`）

导演把一首歌一次规划成不可变的 `ScenePlan`（版面、镜头、转场、触发、标题），播放时只按时间求值。总览在 `docs/ARCHITECTURE.md`。

## 规划（强前瞻）

`plan(input) → ScenePlan`，输入是歌词模型、量好的字、节奏地图、主题。规划顺序：
1. **时间正规化**（lyrics）：快于感知门槛的连续单位合并为一组。
2. **歌词框**：先决定哪些词有框，框的外轮廓计入该组的占位。
3. **居中镜头**（`centerLayout`）：每组最多占三列（以换行后的列数计：三句短句；一句换成两列的加一句短句；三列以上的长句单独一组），严格依序放在中间、上方、下方；每组之后一次转场（`reason: 'layout'`，下一行紧接时用快转场），整组在转场中一起退场。关闭转场时，整组改在下一组第一句出现时一起淡出（`leaves`，由 `plan.ts` 在分段之后套用）。
   **字间距放大淡出**（`tout: 'spread'`）：排版时把多字母的单位（一个唱的音节）拆成单个字母，各字母沿用音节的时间；从该行第一个词的入场动画完成起，字母间距持续缓慢放大，直到该行消失（唱完后 2.2 秒；居中镜头下是整组退场时），最大约字高的 0.2 倍；同时淡出，前段很少、最后才多（`1 − x³`），唱的时候仍清楚可读（`words.ts` 的 `SPREAD`、`SPREAD_GAP`）。时长不随当下的拍速变化，否则拍速逐拍变动时间距会跳。
   **排版**（歌词类型 `lyrictypes.ts` 决定：`stack` 往上下排的机率倍数，「流动」1.45；`orbit` 圆心排法，每段以第一句为圆心（`orbO`），每句以前一句的中心为圆心、选一个角度放上去，但不离开段落圆心约一个画面宽（`ORBIT_RANGE`），角度一律朝「目前偏离圆心那侧的另一侧」（靠近圆心时左右交替），所以从一开始左右就平均；撞到不推开而是换角度；唱完并离开镜头的行立即移除（`plan.ts` 的 `sweepUnseen`）；绕不下时改在圆心周围放（不退回一般排法）；避让只看同段、仍在画面上的行；不用竖排；偶尔转向，转向时只让字顶朝外，角度在 ±100° 内；`depth` 纵深倍数，圆心 2.4，词内取平方根）：沿路径摆字（换行、转折、回折、新段落），不重叠、相邻距离有上限。每次转场（新段落，包括镜头自己加的转场：`plan.ts` 会带着它们重排，最多三轮，直到不再新增）换一个行进方向：往右、往左、往右……，同一段内不再折返，每两次换一次上下（新段落在前面歌词的上方或下方），四段一轮。往左时每一行从前一行开头的左侧、上一列或下一列开始（`back`），每步明显往左（新行中心在前一行开头的左侧），一行接一行往左，任何长度的行都可以往左排；往右的段落里，排到上下列的行中心不会比前一行更左（`onward`）。往左的行（`west`：往回排的、往左段落的第一行、以及画面上明显在前一行左边的）由镜头以「悬停」风格取景（`Stop.hov`）：每组词一个停点、镜头在词组中间上方，往画面左方（行的走向）微微领先并缓慢漂移，不逐字跟随。**不往一个方向走太远**（疾走场景除外）：段落记下起点（`secO`）与尺度（`secR`：第一行宽与一个画面取大者）。离起点超过 `WANDER`（1.8）倍尺度的一半后，下一行一律放在前一行的上方或下方（避开再前一行那一侧，三行上下交错），中心比前一行稍微往起点方向退回；撞到时往上、下或往起点方向推开，不再往前推；竖排之后的下一栏也改放在往起点的那一侧；行首不再转折。超过 `WANDER` 倍尺度的行视为放不下：依序改试下方、（往右的段落）右方，仍不行就快速模糊转场；连快速转场的空档都没有时，才在原页继续（`roam`），且只有真的重叠时，只要有 0.2 秒空档就仍然模糊转场。**同画面最多三行**（`PAGE_LINES` = 3：当前一行和前两行）：第 4 行出现时最旧的一行立即淡出（镜头看得到时 0.5 秒，看不到时直接移除）；排版避让也只看同段仍在画面上的这几行，旧行的位置可以再用。圆心排法所有角度都放不下时，改为模糊转场、开新的圆。
4. **段落转场**：长间奏 → 模糊转场；峰值对齐下一段真正的起点（含弱起），时长以拍计、提前开始。
5. **镜头**：镜头风格是策略（`CameraStyle`）：硬朗切换、平滑滑行、华尔滋。共用的规划器：
   - 每组字一个取景目标（构图沿演唱方向留出前方空间，不锁死中心）；
   - 移动以「位移叠加」构成：`p(t) = p0 + Σ Δᵢ·eᵢ(t)`，相邻移动自然衔接、速度连续；
   - **约束在规划中解决**：正在唱的字必须在安全框内（推迟出发或放宽取景）；超过最远位移阈值就改排模糊转场；
   - 停留时沿演唱方向缓慢漂移（有上限）；
   - **依远近受力**（`project.ts` 的 `depthFeel`）：画面本身的晃动、摇摆、震动与倾斜，依每个字的纵深按视差倍数的平方作用（近的较多、最多 1.3 倍，远的较少、最少 0.35 倍）；推近（缩放）只对远处减弱。逐字的节拍抖动也依纵深缩放。歌词因此各自随距离反应，不像同一个平面图层。
   - **没有歌词的长段落**（前奏、间奏、尾奏）：休息与否看音乐的力度（`driveAt`：歌曲内相对音量，取前后约一秒的平均），不只看有没有字。音乐在推进时，闲置漂浮减弱、不让背景休息（`rest`），每拍的震动加强；从歌词停下起（`wordlessK`，闲置窗口的 `g`）就回应较弱的重拍。音乐安静时才慢慢休息。
   - **歌词框完整入镜**（`fit.ts`）：在镜头实际走的取样路径上（整首歌，不只有框的段落）检查每个框（含边距）和**正在唱的那个字的方框**（`singing()`：取自该字的单位方框，不是词的中心），有超出安全框的就平移、必要时拉远（最多到 0.62 倍），拉远提前开始、延后结束，再以高斯平滑，不跨切镜；拉远的上限只由框决定（`kf`），正在唱的字永远要入镜；需要拉得更远的框提前 0.5 秒淡出。对所有镜头风格、比例（16:9、16:10、1:1、9:16 都有测试）、横排直排一视同仁。
   帷幕：歌词里的 `@N`（N 为 1–9）记下它所在时间戳的时间（逐字歌词是那个字的），不显示；渲染时（`render/curtain.ts`）那一刻帷幕 N 立即盖住画面，停一下后以三次曲线拉开。帷幕用闪光色，拉开处先是背景色再换回画面，歌词随之淡入。帷幕画在画面与字幕之上、萤幕特效之下，固定在萤幕座标。帷幕的时间（提前量、停顿、拉开时长与曲线）在 `director/curtains.ts`，画面与清场共用；帷幕 1 提前约 0.5 秒落下，起步沿用原本的三次曲线，在 0.3 处转为较长的三次减速，速度连续、拉满时间不变。帷幕落下的同时清场（`plan.ts` 的 `applyCurtains`）：在它之前开始的每一行都在那一刻结束，连同译文字幕。新增帷幕只要在 `CURTAINS` 加一项。
   歌词框：歌词里词前的 `$1`（解析时换成一个私用字元，不显示）会在那个词外加框，不受「歌词框线」开关与特写限制；自动挑选的框避开这些行。
6. **效果事件**：闪光、冲击、碎玻璃、光环……全部由节奏地图 `select()` 而来。歌词里的副歌标记（`#1`/`#2`/`#3`，`cues.ts` 的 `markedEntries`）：标记带着自己的时间戳（所在音节的逐字时间，或只有标记的时间戳）时是 `exact`，就在那个时间触发，不吸附到附近的拍；只有整行时间、字的时间是估计的，才吸附到最近的重音。编辑器插入的符号都来自同一份清单（`lyrics/parse.ts` 的 `CUE_SYMBOLS`，介面的 `ui/cues.tsx` 依它生成按键与 Alt 快捷键），新增一种符号只需在清单与解析中各加一处。**没有频率上限**：灵敏度选中的每一个重音都会触发（同一个击打不重复算），设定页附光敏性癫痫提醒。为了让每帧的成本有界，碎玻璃在下一块碎裂后半秒内淡出，同时最多约两块。
7. **标题**：前奏够长 → 片头标题卡；不够 → 顶部小标题，不影响主歌词。结尾标题卡。

`evaluate(plan, t, signals) → SceneFrame`：相机姿态（基本路径 + 动态层：纸盆弹簧、手持漂浮、闲置漂移、冲击）、每个字的状态（入场进度、模糊、透明度）、效果参数。纯函式，可在任意时间取样（导出、预热、测试）。

**投影**：相机姿态 `{x, y, zoom, roll, depth, yaw, pitch}`；字的深度视差以画面尺度的焦距计算；倾斜是有界的透视（|yaw|,|pitch| ≤ 4°，画面座标正规化后计算），与字的世界座标无线性耦合。绘制顺序由规划时决定的稳定键决定。

## 歌词的清理机制（2.21 整理）

画面上的歌词由下面几种机制收掉，依触发的先后列出。除了「离开镜头即移除」只用于圆心排法，其余每种风格都有。

| 机制 | 位置 | 何时触发 | 怎么收 |
|---|---|---|---|
| 段落转场 | `layout.ts`（passages） | 长停顿、新段落、排不下的行 | 全画面模糊转场，转场后是新的一页 |
| 拥挤时的快速清场 | `layout.ts`（CROWD） | 同一页的字太多，且有短暂停顿 | 快速模糊转场 |
| 看不见就移除 | `plan.ts` applySweeps | 拥挤又没有空档转场 | 镜头看不到的行直接移除 |
| 同页最多三行 | `plan.ts`（PAGE_LINES） | 第四行出现 | 最旧的一行 0.5 秒淡出；镜头看不到就直接移除 |
| 离开镜头即移除 | `plan.ts` sweepUnseen（只用于圆心排法） | 唱完的行一离开镜头 | 直接移除 |
| **新旧重叠就淡出（2.21）** | `plan.ts` fadeOverlapped | 新出现的词与仍在画面上的旧行重叠超过较小框的 30% | 旧行从那一刻起 0.25 秒淡出；正在唱的行不受影响 |
| 幕布记号 `@N` | `plan.ts` applyCurtains | 记号的时间点 | 之前的行全部收掉 |
| 字本身的淡出 | `words.ts` | 唱完变暗，整行结束后淡出 | 逐字 |

另外，和声跟着它的主词：主词还在，和声就在；只有主词被上面任一机制收掉时，和声才一起消失（绘制时，主词或和声任一在画面内就会画）。

## 镜头程式（`director/cameras.ts`，3.5.0）

镜头风格是登记表里的一笔「程式」，记着它和别的镜头不同的地方（特征）。规划器（`camera.ts`）、排版（`layout.ts`）、入场（`entry.ts`）、清场（`plan.ts`）与渲染只读特征，**不读镜头的名字**；所以任何风格可以配任何镜头，新增一种镜头是一次登记，不是在导演里到处加 `if`。

| 特征 | 意思 |
| --- | --- |
| `smooth` | 移动有缓动与圆角（只有硬切的「俐落」是 false） |
| `curves` | 走弧线、到达时画面摆动（圆舞一族） |
| `hover` | 停在词组中间上方，不逐字跟随 |
| `close` | 每个字都拉近（自己的远近） |
| `held` | 停在中间、整行取景、不排直栏；有自己的规划器（置中） |
| `follow` | 长词怎么走：`punch` 快速冲到每个字、`step` 稳定一步步、`run` 不停 |
| `cruise` | 移动保持进入时的速度，不在每站减速 |
| `lead`、`drift` | 提前出发的量（120 BPM 一拍的比例）、停留时漂移的速度 |
| `cone`、`coneRoll` | 到达时画面的前倾与滚转 |
| `kicks` | 重音落点时画面弹一下 |
| `lookahead` | 路径往下一站平滑的前瞻秒数；0 表示不平滑（硬切或特写） |
| `flashRise`、`flashPeak` | 重音闪光的上升时间与峰值 |
| `soften` | 规划好的路径再柔化多少：位置、滚转、远近（秒） |

六个内建程式：俐落（punch）、圆舞（waltz）、滑行（glide）、特写（close）、悬浮（hover）、置中（center）。数值见 `cameras.ts` 的登记；`cameraProgram(id)` 遇到不认识的 id 回传滑行。

**新增一种镜头**：在 `cameras.ts` 用 `registerCamera({...base, id, label, …})` 登记，只改和 `base` 不同的特征；需要完全不同的走法时，第二个参数给它自己的规划器（像置中）。在字典加 `cut.<id>`，在 `docs/COPY.md` 加名字。设定页的镜头选单由 `cameraPrograms()` 列出，不必改介面。

## 转场的时机与样子

导演只决定**什么时候**转场（`passages.ts`：长停顿、新段落、拥挤、排不下），以及每段的上升、峰值（切镜）与清除。**转场看起来怎样**在渲染层（`render/transitions.ts`，见 `docs/parts/render.md`），由风格的 `transFx` 选。
