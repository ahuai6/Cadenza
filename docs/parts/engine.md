# 引擎（`src/engine`）

Session（一首歌的一切）与 Engine（时钟、画布、输出、交接、汇出）。介面只经过 `src/engine/index.ts` 使用它。总览在 `docs/ARCHITECTURE.md`。

## 介面

```ts
const engine = new Engine(canvas, platform)
const s = await engine.open(spec)          // Session：音讯 + 节奏 + 歌词 + 样式 → plan（在闲置时预先建好下一首）
engine.show(s, { transition: 'song' })     // 切歌：两个 session 同时渲染、交叉过渡
engine.view.to('effect', handoff)          // 环境（播放页背景）↔ 特效歌词，共享元素由引擎接手
engine.transport.play() / pause() / seek(t)
engine.export(s, opts)                     // 以独立的渲染器实例导出，不改动任何共享状态
configure(engine, { render, gfx, mv, rhythm }) // 宿主（桌面介面、工坊、测试）设定引擎的唯一入口
```
- **编辑与重建**（`session.ts`）：每个编辑只标记它需要的重建——整个重新规划（`REPLAN`）、从歌词起重建（`BUILD`：歌词、分词、字体、范围、速度）、只重算时间（`RETIME`：歌词微调、片尾长度，不重新解析和分词）、只重算特效触发（`RECUE`：碎玻璃、字形纹样、色散、故障的开关，触发灵敏度、字形纹样频率）。重建同一时间只跑一个（`flush`）；重建期间每帧都会再要求，都并入同一个，期间的新编辑由下一轮处理。旋钮各自读到哪一层见 `KNOB_REBUILD`。
- **规划在背景执行绪**（2.12，`engine/planner.ts`、`engine/plan.worker.ts`）：重新规划（版面、镜头、触发、标题）在 Worker 里做，画面照旧用目前的规划继续播放，新的规划好了才一次换上。
  - 导演层本来就是纯计算；唯一需要页面的是每个词在这首歌字体下的宽度。页面先把版面可能问到的每个词都量好（`measuresFor`：每个词横排和直排各一份，加上和声；拆字退场时按字量），连同样式一起送过去，Worker 用 `tableMeasurer` 查表排版。单元测试确认查表排出的规划和直接量的完全相同、没有漏量的词，并且经过结构化复制后不变。
  - 节奏图在 Worker 里用同一份分析重建（分析送一次后按键保留最近几份，之后只送键）。
  - 时间、节奏图、歌词模型和规划一起换上（`retime`），不会出现新节奏图配旧规划的画面；串流分析的新结果（`stage`）也在 Worker 里规划。
  - 没有 Worker（单元测试）或 Worker 失败时，同一个规划器在页面上执行。
- **滑杆**（`app/ui/kit.tsx`）：`onChange` 在拖动中每一步呼叫，只放即时预览（只影响画面的部分）；`onCommit` 在放开或键盘步进时呼叫一次，放需要重建的部分。旋钮拖动时用 `setKnob(k, v, true)` 只更新画面，放开后才重新规划。
- **MV**：MV 是叠在歌曲自己主题上的一层。比歌曲短时，在结束前淡出（`MvSource.endK`），之后画面就是这首歌没有 MV 的样子——主题照它目前的设定，MV 的裁切也解除；预览与汇出一致。
- **设定**：各层的设定（`render/gfx.ts` 的画质模式、`rhythm` 的引擎选择／鼓声分离／模型位置、渲染尺寸、MV 外观）都只从 `configure()` 设定。介面在 `app/engineConfig.ts` 把使用者设定转成 `EngineConfig`。
- **导出的画质**：每一帧都在 `withGfx('default', …)` 中同步绘制。即时画面保持自己的模式，导出期间改设定也不会被还原。
- **神经网路分析排队**：同一时间只跑一首歌，因为 Worker 中的网路会共用缓冲区。即将播放的歌（`urgent`）优先：
  - 它会插到背景歌曲前面；
  - 若此时正有一首背景歌曲在跑，那次分析会中止，该歌之后再重跑一次，不会退回内建分析。
- **多页面并行渲染**：播放页背景就是引擎（环境视图）；特效视图在背景预热（规划、字形快取、精灵图）；切歌时新旧两个 session 同时渲染并交叉过渡。
- **共享元素过渡**：介面量出 DOM 封面与歌词行的位置交给 `handoff`；引擎从那些位置把封面（旋转角同步、黑胶从封面下滑出）与歌词行飞到场景位置；萤幕特效依过渡进度连续变化。返回时反向。
- **模糊转场不抽搐**：
  - 缩小用逐级减半的平均（`gfx.ts` 的 `downsample`），不是一次缩到很小（一次缩 6 倍以上的双线性取样会产生闪烁的锯齿）；模糊半径换算到缩小后的尺度，下限 1.5 像素，画面上永远看不出低解析度那一层。
  - 转场前后 0.5 秒内不调整自适应解析度（解析度一变，字形快取也要重建）。
  - 转场峰值之后的第一帧在转场开始前就预热（`lookAhead`），切点后不会因为第一次绘制而卡一下。
- **歌词写入标签**（`electron/library.cjs` 的 `writeTagLyrics`，node-taglib-sharp）：在同一资料夹的隐藏暂存副本上写入，完成后改名覆盖原档（被占用时重试）；Hi-Fi 输出时先让解码器关闭档案（`stop`），写完从原位置重新载入。格式不支援时改存 `.lrc`。设定「歌词储存位置」可选标签或 `.lrc`。
