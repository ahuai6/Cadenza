# G5.5-R 歌词来源、字段事务和后台活动

## 文档与写入

`lib:lyricSources` 返回来源、格式、实际字段、修订号和可用目标。传统播放接口仍返回选中的来源。旧优先级设置仅在没有明确选择时使用。播放器允许试听当前文档或组合，确认迁移才修改原文件。

`src/lyrics/document.ts` 使用原始 XML 创建编辑投影。剪裁成供播放使用的歌词行是独立步骤。按行视图只编辑对应 XML 节点或属性，不重新生成其他语言轨、背景人声或未知扩展。浏览器 XML 序列化允许引号、声明和空元素书写形式变化，字段读回检查比较的是实际保存的文本。

保存经编辑模式授权及源修订校验。外置来源按所选实际文件处理，更新保留恢复副本。标签写入与 G2 文件释放协调一致，删除保留原文件备份。临时文件校验失败时保留原文件，草稿继续可用。

| 来源 | 读取 | 创建、更新及删除 | 保存检查 |
| --- | --- | --- | --- |
| 外置 LRC、TTML | 独立发现 | 按所选来源操作 | 修订校验，写入临时文件，新建时排除已存在目标 |
| FLAC Vorbis Comment | 独立发现 TTML、LYRICS、LYRIC、UNSYNCEDLYRICS，保留重复字段 | 已发现字段可单独保存和删除，可新建 TTML、LYRICS | 核对全部元数据块与实际编码音频字节的 SHA-256 |
| MP4 / M4A 的单一 ©lyr | 按内容识别 TTML 或 LRC | 可创建、更新及删除 | 专用 Apple 标签，回读目标，比较其他标签与 MP4 媒体负载，再验证 G5 内容身份 |
| MP3 的 ID3v2 USLT | 发现语言和描述符 | 可通过所选帧更新、删除，或新建 Cadenza USLT | 回读该族歌词字段，比较解析可见的其他标签及内容身份 |
| 单逻辑流 Ogg Vorbis、Ogg Opus | 发现单独的歌词评论字段 | 可创建 TTML 和 LYRICS，或更新和删除明确字段 | 回读字段集合，比较解析可见的其他标签及内容身份 |
| 其他内嵌标签和格式 | 显示能识别的来源 | 提供外置目标 | 多个 ©lyr、未识别的扩展字段、ID3 SYLT 和多流 Ogg 使用只读保护 |

FLAC 块格式参考 [RFC 9639](https://www.rfc-editor.org/rfc/rfc9639)，Opus 评论参考 [RFC 7845](https://www.rfc-editor.org/rfc/rfc7845)。ID3 帧语义参考 [ID3v2.4 原生帧](https://id3.org/id3v2.4.0-frames)。编辑时保留 TTML 原始 XML 层级和没被选中修改的节点，标准词汇与命名空间参考 [W3C TTML2](https://www.w3.org/TR/ttml2/)。

## 曲库后台

手动重新扫描覆盖已配置根目录。Windows 目录变化按父目录合并、去重，子树列表异常时保留曲目及用户资料。元数据仍依据文件状态增量读取，内容身份仍由 G5 管理。索引失败采用有限退避。曲库按批发布，减少导入时等待整批标签读取的时间。

分析循环遇到不可授权的文件时，本轮跳过该条继续处理其他候选。扫描、指纹或缓存操作带来的唤醒可以在运行期间合并至下一轮。节奏、响度和缓存验证按真实执行状态报告。现有完整 PCM 和压缩文件限额继续用于后台分析。G6 负责分块分析和调度治理。

目录遍历、标签读取、索引指纹尝试、分析任务发放和校验后缓存命中各自计数。统计以本进程为单位。后台详情按需查询，关闭后停止定时刷新。

## 本轮测量

- Windows Electron 实际打开空间歌词编辑器，使用真实双字段 FLAC 的隔离副本，自动匹配 43 / 43 条译文。保存后回读目标 TTML，确认旧 LYRICS 完整保留，原样本 SHA-256 未变。合成文件和真实 FLAC 副本均在全新的资料目录回读确认。
- 两个根目录的合成曲库中，向一处已有子目录新增歌曲，目录遍历、标签读取、指纹尝试分别增加 1 次。使用同一曲库重启，目录遍历 3 次，标签读取与指纹尝试均为 0 次。运行中的分析发放和缓存校验命中另行计数，数字不代表磁盘吞吐或 CPU 测量。
- ALAC 原样本的隔离副本与合成 AAC、16 位及 24 位 ALAC，覆盖逐样本对照、Range、普通音频信号和工坊有声导出。Hi-Fi 分支使用模拟输出端点。
- 两次各约 2.78 秒的空闲采样中，Windows 主进程累计 CPU 时间分别增加 15.625 ms 和 0 ms，进程传输统计分别增加读 31,348 和 44,564 字节、写 13,040 和 12,928 字节。采样期间目录、标签和内容指纹计数均未变化。系统进程传输统计也含非磁盘 I/O，不能作为物理磁盘读写量或整应用性能指标。
