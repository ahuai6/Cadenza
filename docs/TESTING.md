# 测试

4.0.0 重构使用 [3.6.0 隔离基线](BASELINE-3.6.0.md)。其中记录了同一提交的回归结果、普通与模拟 Hi-Fi 的独立时间点及硬件 GPU 帧数据。后续阶段比较时保留同样的环境、素材和测量口径。

## G2 播放生命周期

- `tests/unit/playback-coordinator.test.ts` 用可控后端验证请求代次、重复队列项、暂停时的准备、跳转、失败重试、自然续播以及多次撤销后的资源释放。架构测试验证协调器不能依赖平台桥或视觉层。
- 在隔离的 Windows 本机构建目录，用 Playwright 运行 `node tests/playback-desktop.cjs`。测试合成音频的两路实际执行路径，分别卡住分析 Worker、字体加载与导演，等待输出后才解开，同时检查过期场景、视觉失败、待播放期间暂停和跳转、特效页内的音频 EOF 与媒体 IPC。每路还有超过 100 次快速请求，最后检查输出资源确实停用。模拟设备需要本次源码构建的 Rust 程序。
- `node tests/hifi.cjs` 验证模拟端点写入的样本、暂停/跳转、运行代次、设备释放与文件关闭确认。经典和模拟 Hi-Fi 桌面回归分别从正常 UI 操作，另跑空间回归及 `alpha.1 → alpha.2` 启动回归。应用资料和合成曲库均在独立临时目录。

G2 Windows 本机结果为类型和格式检查通过、39 套单元测试共 387 项、经典桌面 76 项、模拟 Hi-Fi 桌面 19 项、Rust 模拟设备 32 项、空间 28 项、资料生命周期 11 项通过。两路带故障注入及快速切歌的 Electron 专项测试均通过。空间套件使用模拟桥接，媒体键测试在主进程发出实际使用的媒体 IPC。

### 同口径 Windows 播放数据

在构建好的隔离目录运行 `node tests/baseline/playback.cjs <构建目录> <输出目录>`。输出目录必须是 `CADENZA_BASELINE_ROOT` 下不存在的直接子目录。采用 G0 的 12 秒 WAV、相同探针、预读关闭，每路暖切换和缓存冷切换各 30 次，每个指标都获得了 30 个样本。暖切换复用的是同两首歌，G2 的 AudioBuffer 保留策略已改变。

| 路径与场景 | 旧信号结束 G0 → G2 | 新信号出现 G0 → G2 | 完整分析计划 G0 → G2 |
| --- | ---: | ---: | ---: |
| 普通，暖切换 | 47.4 / 67.5 → 14.5 / 21.5 | 82.0 / 126.9 → 75.9 / 91.7 | 46.7 / 67.5 → 47.0 / 65.2 |
| 普通，缓存冷切换 | 150.6 / 173.0 → 12.5 / 21.4 | 188.2 / 212.1 → 74.1 / 85.8 | 152.0 / 173.4 → 131.7 / 156.6 |
| 模拟 Hi-Fi，暖切换 | 27 / 75 → 17 / 30 | 43 / 75 → 23 / 30 | 42.4 / 70.8 → 48.6 / 65.7 |
| 模拟 Hi-Fi，缓存冷切换 | 17 / 170 → 20 / 30 | 139 / 170 → 21 / 30 | 143.2 / 162.8 → 147.8 / 170.5 |

单位为毫秒，均为 P50 / P95。普通输出测 Web Audio 图内信号，模拟 Hi-Fi 测模拟设备输入 PCM。首播单样本的新信号为普通 325.6 → 136.3 ms，模拟 Hi-Fi 537 → 298 ms。Hi-Fi 仍保留首次开设备的静音锁定期，同格式后续切换可复用设备。模拟 Hi-Fi 缓存冷切换的完整视觉计划 P95 从 162.8 到 170.5 ms，声音已经可以独立先到。另用真实 Windows 48 kHz WASAPI 共享设备验证了运行报告、消费 EOF 和释放，未采集端点波形。普通输出仍受整首解码限制，端点实际停声与出声、独占 DAC、时钟漂移与逐字同步误差留待 G3/G4 采集。

## G1 资料生命周期

- `node --test tests/profile.cjs` 验证版本、独立数据代次、清理恢复、4.0.1 保留、显式结构迁移、外部文件、Windows 联接和独占文件句柄。破坏性用例全部在新建的系统临时目录运行。
- 完成本地应用构建后运行 `node --test tests/profile-desktop.cjs`。需要隔离工具目录中的 Playwright，可以用 `CADENZA_PROFILE_RENDERER` 指定构建好的 `dist-app`。此套件用真实 Electron 验证版本更新、同版本重启、旧库导入关闭、共用单实例锁和 `--reset-data`，通过测试入口将应用数据与操作系统集成隔离。
- 安装包与便携包使用同一个启动策略。本地使用 `electron-builder --win --x64 --publish never` 生成包。将 `CADENZA_PROFILE_PORTABLE` 指向便携包，`CADENZA_PROFILE_INSTALLER_PAYLOAD` 指向从安装包解出的 `Cadenza.exe`，运行 `node --test tests/profile-packaged.cjs`。套件用同一合成 profile 验证首次断代、换包继续使用资料和手动重置。执行安装向导与系统安装登记需另用隔离的 Windows 环境。

G1 采用 Windows build 26300 与 Electron 45.1.0 验证。类型检查通过，38 套单元测试共 378 项通过，文件系统 9 项、Electron 启动场景 2 项、打包应用启动场景 1 项通过。经典桌面 76 项和模拟 Hi-Fi 桌面 19 项通过。本机生成未签名的 `4.0.0-alpha.1` 安装包和便携包。安装包解出的应用与实际便携包已启动验证，安装向导和系统登记未实际执行。正式 4.0.0 和 4.0.1 由隔离测试构建标记模拟。

## 渲染测试的性能门槛（3.5.0 重新校准）

这个环境的浏览器以软件绘图，比显卡慢数倍，而且快慢随机器而变：以毫秒为门槛时，同一份代码在慢的机器上就会失败。所以 `perf` 先量一段**不含 Cadenza 代码的固定画布工作**（渐层、带阴影的文字、缩放复制、读回一个像素）当这台机器的速度，再把每帧的时间换成它的倍数：

- 3.5.0 量到的倍数（三次在 5% 内）：liquid 9.4、gothic 12.5、cover 11。
- 超过基准 25% 才失败。基准要更新时，在 `tests/render.cjs` 的 `BASE` 改数字并写明版本与原因。

性能结论只能来自实机；这里的数字只看「有没有变慢」。

## Folia 对照

参考页（`tests/folia-ref/`）在 Folia 的 checkout 里建置，用真正的 Pixi 8 与 Folia 自己的 React 背景；Cadenza 这边用 harness（`npx vite build --mode harness`）。参考页需要的套件照 Folia 的 lockfile 版本另外装进 checkout 的 `node_modules`（在 checkout 里直接 `npm install` 会被它的 git 依赖挡住）。

```
node tests/folia-stage-compare.cjs <checkout> <输出>                                # 舞台：文字、图形、模糊、滤镜、遮罩
node tests/folia-compare.cjs <checkout> <输出> sonnet,tempera 0.5                    # 全曲逐格（静止）
node tests/folia-compare.cjs <checkout> <输出> sonnet-beat,tempera-beat 2.1          # 播放中、拍点特效打开
node tests/folia-bg-compare.cjs <checkout> <输出>                                   # 五种背景（静止）＋动态（几何图形、莫奈漂移）
```

做法与注意：

- 两边的 `Math.random` 换成同一个固定种子（Folia 有几处细节用真乱数）。每格在全新状态下画。
- **拍点对照**：两边装同一份合成拍点清单，在虚拟时钟（`performance.now` 被换掉）上以每秒 60 步走过时间点前 1.5 秒，再画那一格。
- **动态背景对照**：Folia 的几何图形与莫奈漂移是浏览器动画，暂停后设到同一时刻（`BG.seek`）；几何图形的版面由同一个种子产生（`BG.seed`）。参考页用 1920×1080：Cadenza 把 Folia 的 CSS 像素当成 1080p 页面的大小。
- 软件 WebGL 偶尔掉格，脚本会重画；磁盘配额用完时浏览器会直接崩溃，先清空间。

3.5.0 的结果（平均色差，越小越像）：

| 对照 | 结果 |
| --- | --- |
| 五种背景（静止） | 0.00%–0.14% |
| 通用背景的几何图形（1、7、13.5、29、61 秒） | 0.02% |
| 莫奈的漂移（6、17、40 秒） | 0.25%（0.5 秒时 0.44%，是淡入） |
| 商籁，静止／播放中 | 粗略重合率 95%／95%；拍点反应两边逐格一致（开关拍点造成的变化两边完全相同） |
| 凝彩，静止／播放中 | 粗略重合率 98%／99%；剩下的差异来自 Folia 在播放状态另以墙钟时间驱动的色块动画，不是拍点 |
